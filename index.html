How this works

  1. Add/edit .md notes in any folder (Obsidian vault) — notes stay markdown, no HTML needed.
  2. Commit & push to the repo.
  3. This page reloads the file list from GitHub automatically — the hierarchy updates by itself.
  4. Click a .md file → opens the rendered note on GitHub. Click a .html file → opens the page.
