# 👑 GROUP A — CARDIOVASCULAR + RESPIRATORY

## A1. Atherosclerosis (Item 1) — HIGH-YIELD
**Definition:** Chronic progressive intimal disease of large & medium arteries → plaque of intima composed of lipid, inflammatory cells, smooth muscle, fibrous tissue.

**Risk factors** (always listed):
| Category | Factors |
|---|---|
| Non-modifiable | Age, male sex, family history/genetics |
| Modifiable | 🔴 **Smoking, HTN, DM, hyperlipidemia (↑LDL ↓HDL), obesity** |
| Emerging | ↑hsCRP, Lp(a), homocysteine |

🎯 **"SMOKE-DM-HTN-LIPID"**

**Causative site macrovascular:** Aorta → coronary → carotid → cerebral → iliac/femoral. Opposite of medial calcification (Monckeberg = vessels of lower limb, no narrowing).

**Pathogenesis chain (must write):**
```
Endothelial injury (hemodynamic stress at branches)
   → ↑permeability → lipid (LDL) deposition → oxidation
   → monocyte adhesion → macrophage → FOAM CELL
   → SMC migration + proliferation → collagen/fibrous cap
   → T-cell inflammation → GROWING FIBROUS PLAQUE
   → complications: RUPTURE → thrombosis; hemorrhage; aneurysm; embolism
```

**Plaque morphology:** fatty streak → fibrous plaque → complicated (rupture, thrombosis, ulceration, hemorrhage). **Foam cell** = lipid-laden macrophage, hallmark.

**Acute plaque change ("unstable plaque"):** thin fibrous cap, large lipid core, ↑inflammation → RUPTURE → acute coronary syndrome.

🎯 **"Fatty streak → fibrous plaque → COMPLICATED plaque (rupture/thrombosis/hemorrhage)"**

## A2. Myocardial Infarction (Item 2) — MUST KNOW

**Definition:** Irreversible ischemic necrosis of myocardium, almost always from coronary atherosclerosis + thrombosis.

**Pathogenesis chain:**
```
Plaque rupture/erosion → platelet aggregation → thrombus occludes vessel
   → transmural (ST-elevation) MI = total occlusion of a main coronary
   → subendocardial (NSTEMI) = distal partial occlusion / triple-vessel disease
   → irreversible cell death within 20-40 min of total ischemia
```

**Four-vessel supply:**
- LAD (left anterior descending) → anterior wall, anterior septum, apex — MOST COMMON
- RCA (right coronary) → posterior-inferior wall + RV + SA/AV node
- LCX (left circumflex) → lateral wall
- Right dominance 90% → RCA supplies posterior/inferior

🎯 **"LAD = anterior & APICAL (most common site); RCA = inferior + conduction; LCX = lateral."**

**Temporal morphology (RHUMA time-line):**
| Time | Histology/Gross |
|---|---|
| 0-4 h | No visible change (gross invisible; diagnosis by serum troponin) |
| 4-12 h | Coagulation necrosis → **early wavy fibers + contraction bands** |
| 12-24 h | **Coagulation necrosis, neutrophil influx**, red border |
| 1-3 days | Maximal neutrophils, grossly **yellow-tan softening** |
| 4-7 days | Dead fibers removal, granulation + macrophages |
| 2-8 weeks | **Dense collagenous scar** |

🎯 **"TIME = the written question: 4-12h wavy/contraction, 12-24h + neutrophils, 1-3d yellow, 4-7d granulation, 8wk scar."**

**Cardiac enzymes (Arif/Robbins):**
| Marker | Rise | Peak | Normalization | Use |
|---|---|---|---|---|
| **Troponin I/T** | 2-4 h | 24-48 h | 1-2 wk | 🔴 STABLE-specific, gold standard; still ↑ late |
| **CK-MB** | 3-6 h | 12-24 h | 2-3 days | Early, less specific; detects reinfarction |
| **Myoglobin** | 1-4 h | 6-7 h | 24 h | Earliest, NOT cardiac-specific |
| **LDH** | 24-48 h | 3-6 days | 8-14 days | Late; obsolete |

🎯 **"Myo→CK-MB→Troponin→LDH = rise sequence (M-CT-L)"**

**Complications (7 — list all in written):** arrhythmia (most common cause of early death), cardiogenic shock, rupture (free wall→tamponade, septum, papillary muscle), ventricular aneurysm, mural thrombus → embolism, pericarditis (Dressler = autoimmune, weeks later), heart failure.

**Angina classification:** Stable (exertion, reversible, fixed stenosis) · Prinzmetal/vasospastic (rest, transient ST↑, normal coronaries) · Unstable (crescendo, pre-infarction). Angina = reversible ischemia; MI = irreversible.

**Hypertension:** Definition ≥130/80 (ACC/AHA) / ≥140/90 (older). Essential (primary, 90-95%) vs secondary (renal, renovascular, endocrine, coarctation). **Malignant HTN** = severe ↑ with retinal papilledema, fibrinoid necrosis of arterioles.

## A3. Rheumatic Heart Disease + Infective Endocarditis (Item 3)

**Rheumatic fever (RF):** multisystem autoimmune disease following **Group A β-hemolytic Streptococcus (GAS)** pharyngitis (NOT skin — glomerulonephritis strains differ). Cross-reacting antibodies vs M protein → heart, joints, skin, CNS.

**Jones criteria (updated):**
- Major: **Carditis, Polyarthritis, Chorea, Erythema marginatum, Subcutaneous nodules**
- Minor: fever, arthralgia, ↑ESR/CRP, prolonged PR
- Evidence: **Sustained ↑ASO/anti-DNase B + prior GAS**

🎯 **"CARDIAC: Carditis, Arthritis, Rheumatic chorea, Down under (nodules), Erythema marginatum"**

**RHD morphology:**
- **Aschoff bodies** = pathognomonic granuloma: central fibrinoid necrosis + **Anitschkow cells** (owl-eye nucleus, caterpillar cells) + Aschoff giant cells + lymphocytes.
- **MacCallum patch** (left atrium).
- **Chronic RHD:** fibrous thickening, fusion/commissural fusion of valves, thickened chordae → **mitral valve most affected** (fish-mouth stenosis), then aortic.

🎯 **"Mitral #1, then aortic. Vegetation = small, non-infective, verrucous along line of closure (Lambl excrescences without bacteria)."**

**Infective endocarditis (IE):**
| Feature | Acute | Subacute |
|---|---|---|
| Organism | **S. aureus** | **Viridans group streptococci** (alpha-hemolytic) |
| Valve | Normal valve | Damaged valve (rheumatic, prosthetic, mitral prolapse) |
| Timing | Rapid destructive | Indolent, weeks-months |
| Vegetation | Large, friable | Smaller |

**Predisposition:** damaged endocardium + bacteremia + organisms that ADHERE (fibrin-platelet vegetations). **Etiopathogenesis chain:** Turbulent flow → endothelial damage → sterile fibrin-platelet vegetation → transient bacteremia → infection → growth.

**Complications:** emboli (brain→stroke, kidney, spleen), mycotic aneurysm, abscess/ring abscess, valve destruction→heart failure, glomerulonephritis (immune complex), Osler nodes, Janeway lesions, Roth spots, splinter hemorrhages.

**Vegetation types (classic viva):**
1. **Rheumatic verrucous** = sterile, small, on valve line of closure
2. **Nonbacterial thrombotic (marantic)** = sterile, cachexia/CA
3. **Infective** = infected fibrin-platelet

🎯 **"IE = INFECTED fibrin-platelet vegetation on a damaged valve; S. viridans in subacute (dental), aureus in acute (IVDU, destructive)."**

**Pericarditis causes:** Infective (viral Coxsackie B → most common, TB, pyogenic), uremic, post-MI (Dressler), neoplastic, autoimmune (SLE, RA), radiation. **Comparison of effusions:** serous = HF/hypoalbuminemia; serofibrinous = infection/SLE/RF; hemorrhagic = TB/malignancy/uremia; suppurative = pyogenic.

**Cardiomyopathy:**
- Dilated (DCM): heart = large globular "flabby bag with pear-shaped reSt of congestive bub" → balls, 4-chamber dilation, systolic failure; causes = genetic, alcohol, peripartum, myocarditis.
- Hypertrophic (HCM): myocardial hypertrophy w/o dilation, **asymmetric septal hypertrophy, MYH7/MYBPC3 mutations**, myocyte disarray + fibrosis → LVOT obstruction, sudden death in athletes.
- Restrictive: stiff/fibrotic → diastolic failure; causes = amyloidosis, sarcoidosis, hemochromatosis, endomyocardial fibrosis.

🎯 **"Dilated = big flabby, pump fails; Hypertrophic = thick septum, athlete sudden death; Restrictive = stiff, diastolic (amyloid!)"**

## A4. Pneumonia + TB (Item 4) — MUST KNOW

**Lobar pneumonia — 4 stages (classic written):**
| Stage | Time | Findings |
|---|---|---|
| Congestion | 0-24 h | Fluid+organisms, neutrophils; vascular congestion |
| **Red hepatization** | 2-3 days | Red, liver-like — RBCs outside vessels + fibrin |
| **Gray hepatization** | 4-8 days | Gray, dry — all RBCs lysed, fibrin+neutrophils ✓ |
| Resolution | ~1 wk | Enzymatic liquefaction → macrophage clearing |

🎯 **"Congestion→Red→Gray→Resolution = pneumonia TIME"**

**Lobar vs Bronchopneumonia:**
| | Lobar | Bronchopneumonia |
|---|---|---|
| Extent | Whole lobe | Patchy, peribronchial |
| Organism | **Pneumococcus (Streptococcus pneumoniae)** | Staphylococcus, Klebsiella, Pseudomonas |
| Age | Adults | Children, elderly, debilitated |

**Typical vs Atypical:**
| Feature | Typical | Atypical |
|---|---|---|
| Organism | S. pneumoniae, H. influenzae, M. catarrhalis | **Mycoplasma, Chlamydia, Legionella, viral** |
| Pattern | Lobar/bronchopneumonia | Interstitial ± lobular |
| Pus | **In alveoli** | **In interstitium** (walls) |
| Treatment | Beta-lactam | **Macrolide/Tetracycline** (cell-wall lacking) |

**Resolution must be intra-alveolar inflammation to alveolar macrophages** — otherwise empyema/lung abscess.

**Complications of pneumonia:** abscess, empyema, effusion, bacteremia (meningitis/septic arthritis/IE), sepsis, superinfection, organization→fibrosis, adult respiratory distress syndrome (ARDS).

🎯 **"TYPICAL=alveolar pus (beta-lactam); ATYPICAL=interstitial (macrolide). LobAR=Pneumococcus whole lobe."**

**TUBERCULOSIS (Item 4):**
- **Primary TB:** inhaled → alveolar macrophage → Ghon focus (mid/lower lobe, subpleural) → **Ghon complex = Ghon focus + hilar node (lymphangitis + adenopathy)** → usually heals calcified. Subpleural focus + regional node.
- **Secondary TB:** reactivation in apex (apical seeding), cavitation, cough with hemoptysis; endogenous reactivation > exogenous reinfection. **TB = caseating granuloma: central caseous necrosis + epithelioid cells + Langhans giant cells + lymphocytes + fibroblasts (fibrotic rim).**

🎯 **"Primary = Ghon complex; Secondary = apical reactivation + cavity."**

**Mantoux test:** intradermal PPD → 48-72h induration ≥10mm (immune IX delayed). False negative: miliary, early infection, immunosuppression.
**Miliary TB:** hematogenous spread → multiple tiny yellow-white foci all organs ("milky seed" pattern) — ddx: millet seeds.

## A5. COPD / Asthma / Bronchiectasis / Lung Cancer (Item 5)

🔴 **Obstructive vs Restrictive (VERY HIGH YIELD written):**
| Feature | Obstructive (COPD) | Restrictive |
|---|---|---|
| FEV1/FVC | ↓ | Normal/↑ |
| TLC | ↑ (hyperinflated) | ↓ |
| Cause | Airway obstruction | Interstitial disease |

**Emphysema:** permanent enlargement of airspaces + destruction of walls. Types: **Centriacinar** (#1, smokers, upper lobes) > **Panacinar** (α1-antitrypsin deficiency, lower lobes) > **Paraseptal** + **Irregular (bullous/scar)**. Pathogenesis: **elastase/α1-AT imbalance** + oxidative stress + apoptosis.

🎯 **"Centriacinar = SMOKER's emphysema (upper); Panacinar = alpha-1-AT (lower); elastase-outsmarts-inhibitor."**

**Chronic bronchitis:** **= daily productive cough ≥3 months/yr, ≥2 yrs**. Blue bloater → cor pulmonale. Goblet cell hyperplasia, mucus hypersecretion, Reid index ↑ (gland:wall thickness).

🎯 **"Pink puffer (emphysema) vs Blue bloater (chronic bronchitis)"**

**Asthma:** reversible broncho-obstruction + eosinophilic inflammation + bronchial hyperresponsiveness. **Pathogenesis:** Type I hypersensitivity (allergic/atopic) + nonatopic triggers:
```
Allergen → mast cell degranulation (histamine, leukotrienes C4/D4)
   → early phase: bronchospasm, mucus, edema
   → late phase: IL-4/IL-5 (Th2) → eosinophils → persistent inflammation
   → remodeling: subepithelial basement membrane thickening + smooth muscle hypertrophy → chronic
```
**Gross/micro:** mucus plugs (Curschmann spirals), eosinophils, **Charcot-Leyden crystals** (eosinophil lysophospholipase), basement membrane thickening, hypertrophied glands & muscle.

🎯 **"Asthma = REVERSIBLE + eosinophils; Curschmann spiral + Charcot-Leyden crystals; chronic = remodeling."**

**Bronchiectasis:** permanent dilation of bronchi + destruction of elastic/muscular wall. Causes: **cystic fibrosis** (#1 in children), necrotizing pneumonia, bronchial obstruction (tumor/FB), **Kartagener syndrome** (dextrocardia + sinusitis + situs inversus), allergic bronchopulmonary aspergillosis (ABPA). **Clinical:** chronic productive cough of purulent sputum (paroxysmal), hemoptysis, clubbing; **micro: mucopurulent exudate, neutrophil infiltrate + destroyed elastic layer; bronchial arteries hypertrophy → massive hemoptysis.** Recurrent bouts → fibrosis → cor pulmonale.

🎯 **"Bronchiectasis = permanent dilated pus-filled tubes — CF in kids, Kartagener, obstruction, aspiration."**

## A5b. Lung Cancer (Item 5) — MUST KNOW

**WHO Classification (4 major types):**
| Type | % | Smoking link | Site | Key features |
|---|---|---|---|---|
| **Adenocarcinoma** | ~35-40% (#1 in non-smoker) | Weakest | Peripheral | **Most common today even in non-smokers**; may show **lepidic growth, mucin**, **ground-glass / coin lesions** |
| **Squamous cell** | ~20-30% | Strongest | **Central** (hilar) | **Keratin pearls + intercellular bridges**, cavitation; **P63/p40+**; paraneoplastic PTHrP → hypercalcemia |
| **Small cell** | ~15% | Very strong | **Central** | **Small blue cells, neuroendocrine (CgA/Syn+), oat cell; paraneoplastic (SIADH→hyponatremia, Cushing/ACTH, Lambert-Eaton); most aggressive, chemo-sensitive → but poor prognosis**; t(2;18) |
| **Large cell** | ~10% | Strong | Peripheral | Undifferentiated, NOS (negative markers), 40% resectable |

🎯 **"CENTRAL + smoking = small cell/squamous; PERIPHERAL = adenocarcinoma; kind=oat cell = neuroendocrine."** ⬇ BUT always remember **adenocarcinoma = most common today (even non-smokers)**.

**Paraneoplastic syndromes table (LUNG CA — classic):**
| Syndrome | Cell type | Factor |
|---|---|---|
| Ectopic ACTH (Cushing) | Small cell | ACTH |
| SIADH (hyponatremia) | Small cell | ADH |
| Lambert-Eaton (myasthenia-like, legs) | Small cell | VGCC antibody |
| Hypercalcemia | **Squamous cell** | PTHrP |
| Clubbing, hypertrophic osteoarthropathy | Adenocarcinoma (also others) | — |
| Gynecomastia | Large cell | hCG |

🎯 **"Small cell = ACTH + ADH + Lambert-Eaton; Squamous cell = calcium (PTHrP); Adenocarcinoma = clubbing/mets early"**

**Pancoast tumor:** superior sulcus → **Horner syndrome** (ptosis, miosis, anhidrosis) + shoulder/arm pain (brachial plexus T1). Destroys the sympathetic chain.

# 👑 GROUP B — GI + HEPATOBILIARY + RENAL

## B1. Stomach: Gastritis / PUD / Gastric Carcinoma (Item 10)

**Gastritis types:**
| | Acute | Chronic |
|---|---|---|
| Cause | NSAIDs, alcohol, stress (Curling burns, Cushing CNS), H. pylori | **H. pylori (#1)** > autoimmune, bile reflux |
| Inflammation | Neutrophils | Lymphocytes/plasma cells |
| Outcome | Often reversible | Atrophy → metaplasia → carcinoma |

**Chronic gastritis — the Big Two:**
| | H. pylori (Type B) | Autoimmune (Type A) |
|---|---|---|
| Site | **Antrum** > corpus | **Corpus/fundus** |
| Acid | ↑ or normal (early) | ↓ (achlorhydria) |
| Mechanism | CagA, urease, mucosal immunity (neutrophils) | **Anti-parietal cell + anti-intrinsic factor antibodies** |
| Vitamin B12 | Normal | **Pernicious anemia** |
| Cancer risk | Gastric (adenocarcinoma, MALT lymphoma) | **Gastric carcinoid (ECL hyperplasia/neuroendocrine), gastric Ca** |

🎯 **"H. pylori = ANTRAL (gastric ulcer + MALT + adenocarcinoma); Autoimmune = CORPAL (pernicious anemia, achlorhydria → carcinoid); Hp down = hyval acidic."**

**Peptic ulcer (PUD):**
- **Defensive factors:** mucus-bicarbonate layer, prostaglandin (maintains mucus), blood flow. **Aggressive:** acid, pepsin, H. pylori (90% duodenal, 70% gastric), NSAIDs (impaired prostaglandin).
- **Location:** Duodenal (duodenal 1st part) — **#1**: burning pain 90 min-3h after meals; relieved by food/antacids. Gastric (antrum near angulus) — pain worse with eating.
- **Benign vs malignant - THE classic table (100% exam):**
| Feature | Benign ulcer | Malignant ulcer |
|---|---|---|
| Edge | **Flat, punched-out, regular** | **Raised, everted, irregular (heaped-up)** |
| Floor | **Clean, smooth** | **Necrotic, dirty, shaggy** |
| Surrounding mucosa | Smooth, folds radiate | Nodular, **folds do not radiate** |
| Base | **Disc/button** | Irregular, invasive |
| Sites | **Duodenal, lesser curve (antral-angulus junction)** | Greater curvature, fundus |
| Hour-glass / saddle deformity | Common (fibrosis) | Not characteristic |
| Size | Usually < 2.5 cm | Usually > 6 cm (large) |
| Age | Young adult | Older (50+) |
| Weight loss | Rare | **Marked** |
| Response to anti-H2/PPI | Yes (heals) | **No / transient** |
🎯 **"Benign = stepped-out, clean, folds radiate & heals. Malignant = raised rolled edge, dirty, folds STOP."**

- **Complications:** **bleeding (most common), perforation (→ peritonitis), penetration, obstruction (pyloric stenosis).**

**H. pylori chain: optimize in written:**
```
Adheres → urease → ammonia neutralizes acid → CagA into epithelial cells
   → IL-8 → neutrophil recruitment
   → gastrin deregulation (↑acid) → DUODENAL ulcer
   OR → mucosa damage → antral gastritis → atrophy → gastric ulcer/carcinoma
```

🎯 **"Hp = urease → colonize antrum → ↑acid for duodenal ulcer / ↓defense for gastric ulcer / risk of MALT + adenocarcinoma"**

**Gastric carcinoma:** #1 = intestinal type (intestinal metaplasia → dysplasia → carcinoma, H. pylori, least risk in corpus). **Diffuse type = Borrmann 4 / linitis plastica (leather-bottle, signet-ring cells, worse).** **Signet ring cells** push nucleus aside (CTA). Metastases: **Virchow node (left supraclavicular), Sister Mary Joseph node (umbilicus), Krukenberg tumor (ovary bilateral)**.

## B2. Intestine: IBD / Appendicitis / CRC / Polyps (Item 11)

**Crohn vs Ulcerative colitis — the #1 compare table:**
| Feature | **Crohn** | **UC** |
|---|---|---|
| Site | **Mouth→anus, terminal ileum most** | **Colon only; rectum ALWAYS involved** |
| Pattern | **Segmental SKIP lesions** | **Continuous** |
| Depth | **Transmural (full-thickness)** | **Mucosa/submucosa only** |
| Gross | Cobblestone, aphthous/linear ulcers, **creeping fat**, strictures | Friable granular, **pseudopolyps**, superficial ulcers |
| Micro | **Noncaseating granulomas (~35%)**, fissures | **Crypt abscesses**, crypt distortion, goblet depletion |
| Diarrhea | Usually non-bloody | **Bloody + mucus + tenesmus** |
| Pain | RLQ | LLQ |
| Fistulas/perianal | **Common** | Rare/absent |
| Toxic megacolon | Rare | **Classic** |
| Smoking | **Worsens** | **Protective** |
| Serology | ASCA+ | pANCA+ |
| Gene | NOD2, ATG16L1 | HLA, IL10 |
| Cancer risk | ↑ | **Higher (8-10yr surveillance)** |
| Surgery | Not curative (recurrence) | **Colectomy CURATIVE** |

🎯 **"Crohn SKIPS, is TRANSMURAL, has GRANULOMAS + fistulas, loves smokers. UC CONTIGUOUS, MUCOSAL, crypt abscess + pseudopolyps + toxic megacolon, smoking PROTECTS"**

**IBD vs IBS (short version):** IBD = organic inflammation + alarm signs (bleeding, weight loss, ↑calproctin/CRP) + complications; IBS = functional, **normal endoscopy & histology**, pain relieved by defecation, Rome criteria, NO blood.

**Acute appendicitis is always an obstruction->ischemia story:**
```
Obstruction (fecalith adult / lymphoid hyperplasia child / FB / tumor)
   → mucus retention → ↑intraluminal pressure → venous congestion → ischemia
   → bacterial invasion (E. coli, Bacteroides) → transmural suppuration → perforation
```
**Complications:** perforation → localized abscess OR general peritonitis → **portal pylephlebitis → multiple liver abscesses** → adhesions → obstruction; female tubal infertility.

🎯 **"Obstruct → pressure → ischemia → bacteria → gangrene → perforation → peritonitis/pylephlebitis"**

**Colorectal carcinoma — two pathways:**
```
A) CLASSIC (chromosomal instability, LEFT colon, napkin-ring):
APC loss (5q21) → β-catenin/↑MYC (early adenoma)
   → KRAS (large adenoma) → SMAD2/4 loss → TP53 loss → CARCINOMA
B) MSI pathway (RIGHT colon, bulky mucinous, BETTER prognosis):
mismatch-repair loss (MLH1 methylation or Lynch germline) ± BRAF → MSI-high
```
**Risk factors:** age>50, IBD 8-10yr, adenomas, red meat/low fiber, **FAP (APC germline, 100% by 40-50), Lynch/HNPCC (MMR genes, MSI, right colon + endometrial CA)**.

🎯 **"Left = APC→KRAS→TPS3 (chromosomal, annular); Right = MSI/BRAF (mucinous, Lynch-like, better)"**

**Polyps: non-neoplastic (hyperplastic-left colon, inflammatory, hamartomatous-Juvenile/PJ/Cowden) vs NEOPLASTIC ADENOMAS (tubular<25% villous → tubulovillous 25-75 → villous>75% = highest risk).** Malignant risk: **size>1cm, villous, high-grade dysplasia, sessile.**

**GIST = Cajal cell tumor: KIT (CD117)+, DOG1+, imatinib-responsive; gastric 60%.**

**Appendiceal #1 = carcinoid (well-differentiated NEN) at tip; <2cm appendectomy curative; ≥2cm → hemicolectomy. LAMN rupture → pseudomyxoma peritonei (jelly belly + HIPEC).**

## B3. Hepatitis / LFT / Jaundice (Item 12)

**Acute viral hepatitis — the Big 5:**
| Virus | Type | Transmission | Chronic? | Cardio key |
|---|---|---|---|---|
| **A** | RNA, ss(+) | **Fecal-oral** | No | Never chronic; self-limited |
| **B** | DNA, double-stranded | **Blood/sexual/perinatal** | Yes (5-10% adults, 90% perinatal) | **Dane particle; vaccine** |
| **C** | RNA | **Blood (IVDU, transfusion)** | **Yes (70-80%)** | #1 cause chronic liver disease → cirrhosis + HCC |
| **D** | RNA (defective) | Blood | With B | Requires HBV; worsens |
| **E** | RNA | Fecal-oral | No | **Pregnant → fulminant mortality** |

🎯 **"A+E = enteric (water-food); B+C+D = blood-borne; C = chronicity #1"**

**HBV serology (memorise for MCQ):**
| Marker | Meaning |
|---|---|
| **HBsAg** | Acute/chronic infection (present) |
| **Anti-HBs** | Recovery/vaccination (protective) |
| **HBeAg** | Active viral replication/传染 |
| **Anti-HBe** | Low replication |
| **Anti-HBc IgM** | Acute infection |
| **Anti-HBc IgG** | Past infection |
| **HBV DNA** | Viral load (reactivation, for treatment) |

🎯 **"HBs = surface (carrier/infection); anti-HBs = immunity; HBe = active virus; core IgM = acute"**

**Jaundice/LFT patterns (MUST annotation):**
| Biochemistry | Pre-hepatic (hemolytic) | Hepatocellular | Obstructive |
|---|---|---|---|
| **Bilirubin (total/indirect)** | ↑ indirect | ↑ both | ↑ both |
| **Direct bilirubin (in urine)** | Absent (acholuric) | Present | **Present** |
| **Urine bilirubin** | Negative | Positive | Positive |
| **Urobilinogen (urine)** | **↑↑ (increased)** | ↑ | ↓/absent (obstruction) |
| **ALT/AST** | Normal | **↑↑↑ (2-3×obstructive)** | ↑ mild |
| **ALP** | Normal | Mild | **↑↑ (biliary)** |
| GGT | Normal | Mild | ↑↑ |
🎯 **"Hemolytic = ↑indirect + urine stays CLEAR + urobilinogen ↑; Obstruction = ↑direct/ALP + pale stool; Hepatocellular = ALT jump"**

**LFT reference:* total bilirubin 0.2-1.2 mg/dL, direct <0.3; ALT <50 U/L (F>35), AST <45; ALP 44-147 U/L; GGT <60; albumin 3.5-5; PT; ammonia (25-60 μmol/L) for HE.*

**Robbins: liver biopsy findings in acute hepatitis = hepatocyte swelling + ballooning degeneration + Councilman bodies (apoptosis) + lobular disarray + mixed lobular infiltrate ± cholestasis.**

## B4. Cirrhosis / Portal HTN / Liver Failure / HCC (Item 13)

**Cirrhosis = diffuse process: fibrosis + nodular regeneration → architectural destruction → ↓liver function + portal hypertension.**

**Causes (incl Bangladesh):** **Hepatitis B (most common in Bangladesh/Asia), hepatitis C, ALCOHOL, NASH/NAFLD (#1 metabolic), autoimmune, Wilson, hemochromatosis, biliary (PBC/PSC), alpha-1 antitrypsin.**

**Ethiologic classification (Japan/Robbins-ish) + morphologic:** Laennec/alcoholic (micronodular, uniform small) → macronodular (post-necrotic/viral, large, HCC risk higher) → mixed → incomplete septal. **Child-Pugh (A/B/C) grading & METAVIR (F0-F4) staging of fibrosis.**

**Pathogenesis:**
```
Chronic injury (virus/alcohol/NASH)
   → HSC (Ito cell) activation → collagen deposition (starlike)
   + hepatocyte regeneration → fibrous septa + nodules
   + vascular remodeling → PORTAL HYPERTENSION (central, driven by nodular fibrosis
     compressing hepatic venules & increasing resistance)
```
→ **Portal HTN → varices (upper GIT bleed), ascites, splenomegaly + hypersplenism, Caput medusae, hepatic encephalopathy** (ammonia).

**Clinical features/cirrhosis: jaundice, ascites, bleeding/coagulopathy, encephalopathy, hepatorenal/hepatopulmonary syndrome, HCC supervening.**

🔴 **Hepatic encephalopathy:** cause = **ammonia** crossing BBB; precipitates: GI bleed, infection, diuretics/electrolyte, constipation, high protein, sedatives; **astrogliosis (Alzheimer type II) on histology.**

**Acute liver failure:** rapid onset (Hep-2 anticoagulopathic) — causes: **paracetamol (most common in West, centrilobular necrosis), viral (Hep A/B/E), toxins, Wilson, ischemic**.

**HCC:** risk factors = cirrhosis (all causes), HBV/HCV, aflatoxin B1, hemochromatosis; **morphology:** multinodular green/yellow; **α-fetoprotein (AFP) ↑**; breeds in cirrhosis. ## C5. Diabetes (Item 20)

**Type 1 vs Type 2 (the table):**
| Feature | Type 1 (insulin-dependent) | Type 2 |
|---|---|---|
| Age | Children/young | Adults (rising in young, obese) |
| Pathogenesis | **Autoimmune β-cell destruction (anti-GAD, islet cell Ab)** | **Insulin resistance + β-cell dysfunction** |
| Body habitus | Lean/weight loss | **Obese** |
| Ketosis | **Prone (DKA)** | Rare |
| Treatment | **Insulin always (lifelong)** | Lifestyle/diet/meds (↑insulin if needed) |
| Genetics | HLA-DQ/DR, HLA association | Polygenic, obesity + genes |
| Morphology | β-cell insulitis (lymphocytic) → **islet atrophy** | **Amylin (IAPP) amyloid in islets, islet hypertrophy** |
| Acute complication | **DKA** | **HHS (hyperosmolar hyperglycemic state)** |

🎯 **"Type 1 = lean + tissue + DKA + insulin forever (GAD+ killer cells); Type 2 = obese + amyloid islets + HHS"**

**Lab diagnosis (WHO criteria):** fasting ≥126, 2h OGTT ≥200, HbA1C ≥6.5%, random ≥200 + symptoms. **IFG (100-125) & IGT (140-199) = prediabetes.**

**OGTT:** 75g glucose, fasting → measure at 0, 60, 120 min; normal fasting <100, 2h <140; DM = 2h ≥200.

**HBA1c:** reflects ~90 days (glycated), used for monitoring 6.5% diagnostic; **target <7%.**

**Complications (chronic):** **microvascular = nephropathy (Kimmelstiel-Wilson nodular), retinopathy (microaneurysm), neuropathy (peripheral/distal symmetrical + autonomic)**; **macrovascular = accelerated atherosclerosis (MI, stroke, PVD)**; diabetic foot → osteomyelitis.

**DKA pathogenesis chain (must write):**
```
Insulin deficiency + glucagon excess
   → ↑lipolysis → ↑FFA → liver converts to ketone bodies (β-hydroxybutyrate, acetoacetate)
   → ↓glucose utilization + ↑gluconeogenesis → hyperglycemia → osmotic diuresis
   → dehydration + Na/K loss + hyperosmolality
   + metabolic ACIDOSIS (anion gap ↑) → Kussmaul breathing, acetone breath, fruity odor
```
**Hypoglycemia (diabetics):** excessive insulin/oral hypoglycemics, missed meals, exercise, alcohol; symptoms: sweating, tremor, palpitation, confusion, coma; treatment: glucose.

**Test (urine):** reducing sugars → **Benedict brick-red** = ++; **glucose oxidase dipstick (stick/elect) = specific & semi-quantitative**; **renal glycosuria** (pregnancy, renal tubular) = normal blood sugar with glycosuria.
