## 🎯 How to use these notes (read this first)

Pathology is a **tree**. 🌳
```
                            PATHOLOGY (the whole subject)
                                      │
        ┌───────────────┬─────────────┼─────────────┬─────────────┐
   GENERAL PATHOLOGY             (then)        SYSTEMIC PATHOLOGY
   how ALL cells react          │              how EACH organ gets sick
   (Ch 1–9)                     │              (Ch 10–29)
```
Every chapter file follows the **same 5-layer recipe** so nothing ever feels new:

1. **Big Picture** — 1 mindmap of the whole chapter (see the tree before the leaves)
2. **Chapter map** — table of every topic + priority tag + study time
3. **Topic-by-topic** — flowcharts, tables, images, mnemonics
4. **Rapid-fire one-liners** — 1-line Q & A to drill yourself
5. **Flashcards** — end-of-chapter Q&A to test yourself like an examiner

## 🖼️ How visuals work

Every disease's **gross + microscopic (histology) features** have:

- **🔍 Google search buttons** → `[🔍 Gross](https://www.google.com/search?q=...&tbm=isch)` opens Google Images so you can *see* the specimen/histology in 1 click.
- **Curated free links** to stable, license-free teaching sites:
  - [WebPath](https://webpath.med.utah.edu/) — free virtual autopsy & histology lab
  - [PathologyOutlines](https://www.pathologyoutlines.com/) — free textbook-style images
  - [Libre Pathology](https://librepathology.org/) — free image bank
  - [Wikimedia Commons](https://commons.wikimedia.org/) — search any term

> ⚠️ The internet image links are **starting points** — click, look, then describe the image in your head ("this is a wedge-shaped pale kidney = coagulative necrosis"). Seeing + describing = remembering.

**How to read a Mermaid diagram:** the code is inside ` ```mermaid ... ``` ` blocks. They render automatically in Obsidian / GitHub / VS Code (with Mermaid extension). Don't try to memorise the code — memorise the *picture it makes*.

## 🗣️ How Bangla (🇧🇩) is used

- Content = **English** (that's what exams are written in).
- 🇧🇩 appears next to **hard English terms**: meaning + why the name is given + real-life anchor.
- Example: 🇧🇩 **Necrosis** = মৃতকোষ নষ্ট (cell death from outside injury). নামটা গ্রিক "nekros" = মৃত। অর্থ → কোষটা হার্ট অ্যাটাক/টক্সিনে *মারা যায়*।

3. Copy each 📌 line onto paper **once** (writing = memory).

## 🗣️ Study strategy: Viva

- Examiners love: **classifications**, **"first step in..."**, **"most common..."**, **mechanisms**.
- Drill the **❓/✅** pairs out loud. Say the answer *before* revealing.
- For every disease be ready with: **definition → cause → gross → histo → special stain → complications**. (The 🖼️ buttons are your visual aid.)

## 🔄 The 4 questions a pathologist (and examiner!) always asks

Every disease, ask these 4 — they are the **4 pillars of Robbins Ch 2**:
1. **Causation (Etiology)** — *why did it start?*
2. **Mechanism (Pathogenesis)** — *how does it cause disease?*
3. **Morphology (Gross + Microscopic)** — *what does it look like?*
4. **Clinical manifestations** — *what does the patient show?*

> 🇧🇩 এটাই pathology-র আসল কাঠামো: প্রতিটা রোগের জন্য এই ৪টা প্রশ্নের উত্তর দিতে পারলে লিখিত আর ভাইভা দুইটাই ক্লিয়ার।
