## 🎯 Complication clocks

### MI clock (Item-2 Q12 same)

| Time | Event |
|---|---|
| First hours–days | 🔴 Arrhythmia VF — commonest early in-hospital death |
| Anytime (large >40% LV) | 🔴 Shock/LVF — commonest overall hospital death |
| Day 2–4 | Fibrinous pericarditis rub (transmural) |
| 🔴 Day 3–7 soft heart | 🔴 Rupture: free-wall→tamponade / septum→VSD / papillary→acute MR |
| Days–weeks | Mural thrombus → stroke/renal/splenic/limb |
| Weeks–months | Ventricular aneurysm (bulges, NOT rupture) → CHF/VT/emboli |
| 2–10 wk | Dressler autoimmune pericarditis |

### Liver failure clock (Item-13 Q12/Q15)

Encephalopathy asterixis/fetor + PT bleed + deep jaundice + hypoglycemia + cerebral edema death + HRS + sepsis. Falling ALT + rising bili = dissociation ominous (massive necrosis).

### DKA vs HHS vs hypoglycemia (Item-20 Q11–Q13 + PBQ same)

| Feature | DKA (T1) | HHS (T2) | Hypoglycemia |
|---|---|---|---|
| Glucose / ketone | High + ketone fruity + acidosis Kussmaul | Very high no ketone, coma osmolar | Low <70 sweating tremor confusion |
| Trigger | Missed insulin/infection | Infection/dehydration elderly | Excess insulin/OHA missed meal |
| Rx | Insulin + fluid + K | Fluid + insulin | Glucose fast |

## 🎯 Organ-failure pair: HRS vs HPS (Item-13 Q14 same)

- HRS: kidney squeeze — functional vasoconstriction oliguria creat↑ no proteinuria normal tubules, transplant cures; Type 1 rapid SBP/bleed deadly, Type 2 slow ascites.
- HPS: lung stretch — intrapulm dilation shunt PaO2<80 platypnea upright dyspnea orthodeoxia clubbing, transplant cures.

## 🎯 Encephalopathy + coagulopathy mechanism (Item-13 Q16 same)

NH3 gut→BBB astrocyte glutamine Alzheimer II edema + false transmitters (octopamine) → asterixis coma (bleed/constipation/protein/hypoK/alkalosis/sedative worse); factors II/V/VII/IX/X↓ (VIII spared) + platelet↓ hypersplenism → bleed; vitK fixes cholestatic NOT synthetic.

## 📌 Viva traps

1. Day 3–7 chest pain patient suddenly dies? → free-wall rupture tamponade.
2. Weeks later fever + rub post-MI? → Dressler, early rub day 2–4 na.
3. Aneurysm bulges but NOT rupture? → ventricular aneurysm (MI scar).
4. Falling ALT good news? → Na, if bili rising = massive necrosis dissociation.
5. Hypoglycemia vs DKA sweat? → Both sweat, glucose + ketone/acidosis separates.
