```text
Risk (LDL↑ HTN smoke DM family) → endothelial injury → oxLDL → foam cell → fibrous cap
→ VULNERABLE plaque (thin cap <65µm + lipid core >40% + macrophage)
→ rupture/fissure/erosion → collagen+TF expose → platelet-fibrin THROMBUS
→ total occlusion = INFARCT / partial = unstable angina / fly-off = EMBOLUS
```

## B. Angina vs MI — demand vs death (Item-2 Q5 same answer)

| Feature | Angina (<15 min, nitro relief) | MI (>30 min, nitro NO) |
|---|---|---|
| Pathology | Reversible ischemia | 🔴 Irreversible coagulative necrosis |
| Enzyme | Normal | 🔴 Troponin↑ CK-MB↑ |
| ECG | Transient ST change | Persistent ST↑ → Q wave |
| Types | Stable fixed >70% / Prinzmetal spasm rest ST↑ / Unstable fissure mural thrombus | Transmural total occlusion / subendocardial diffuse |

## D. Virchow triad — DVT = PE (Item-4 Q2 same)

Stasis (immobilization/flight/surgery) + endothelial injury + hypercoagulable (OCP/pregnancy/cancer/Factor V Leiden) → popliteal/femoral/iliac thrombus → saddle or wedge infarct (apex-to-hilum, fibrinous pleuritis → hemosiderin → scar).

📌 60–80% silent lyse hoy; 2.5–5% saddle sudden death; recurrent → chronic thromboembolic pulm HTN → cor pulmonale.
