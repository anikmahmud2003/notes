## A. TB everywhere — ekta AFB sob fluid e (Item-4 Q15 + Item-21 + Item-7 Q3)

Sputum 3× spot-morning-spot ZN + GeneXpert MTB/RIF rpoB 2 h WHO-first + LJ/MGIT DST; pleural lymphocyte exudate ADA>40 + biopsy highest yield; CSF lymph low-glucose; urine sterile pyuria; HIV every case; Mantoux supportive only (BCG cross).

## B. Sterile pyuria vs culture-negative IE — "pus/infection kintu culture negative" pair

- Sterile pyuria: TB classic + partial Rx + Chlamydia/Ureaplasma/gono + stone/tumour + papillary necrosis + PKD + appendicitis adjacent (Item-7 Q3).
- Culture-negative IE ~10%: prior antibiotics + Coxiella/Bartonella/HACEK/fungi (Item-3 Q10).

## C. S. aureus everywhere vs viridans only valve — virulence rule

Virulent (aureus) attacks **normal** valve/bone/lung; low-virulence (viridans) needs **damaged** valve. Same rule bone: aureus normal metaphysis, TB/fungal needs special setting.

1. Skin infection RF kore? → Na, only pharyngitis.

5. Foul foul-smelling + clue? → BV Gardnerella; curd + pruritus? → Candida; frothy + strawberry? → Trich.
