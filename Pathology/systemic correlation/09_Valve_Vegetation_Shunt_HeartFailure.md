| Type | Direction | Examples | Fate |
|---|---|---|---|

### TOF PROVe (Item-3 Q1 same)

🔴 Pulmonic infundibular stenosis (severity decides) + Overriding aorta + RVH + VSD. Boot-shaped heart, squatting relief (↑systemic resistance), pink tet mild vs blue severe. Untreated 10% to 20 yr.

## 🎯 RHD acute vs chronic (Item-3 Q16 same)

- **Acute pancarditis:** pericardium bread-butter fibrinous + myocardium Aschoff + valves verrucae + MacCallum plaque LA.
- **Chronic:** leaflet thick/calcify + 🔴 commissural fusion + chordal shorten/fuse → 🔴 fish-mouth/buttonhole MS (99% acquired MS = RHD); LA dilate → AF → mural thrombus → stroke; lung congestion → pulm HTN → cor pulmonale.

## 🎯 IE acute vs subacute (Item-3 Q9–Q10 same)

| Feature | Acute | Subacute |
|---|---|---|
| Organism | 🔴 S. aureus | 🔴 Viridans (mutans/sanguis) |
| Valve | Normal | Damaged (RHD/MVP/bicuspid) |
| Course | Days stormy surgery | Weeks-months antibiotics |
| Special | IVDU tricuspid right | Dental procedure |

📌 Needs bacteremia + surface abnormality; fibrin shield hides germs; Duke: 2 major / 1+3 / 5 minor. Complications 4 baskets: Destroy (valve/regurg→HF commonest death) / Travel (septic emboli + mycotic aneurysm) / React (GN + Osler + Roth + RF+) / Drain (ring abscess → heart block).

## 🎯 Pericarditis types (Item-3 Q7/Q13 same)

Serous (viral/RF/SLE/uremia) / 🔴 fibrinous commonest (MI day 2–4 + Dressler weeks autoimmune + uremia + RF + surgery/radiation, bread-butter + rub) / purulent (pneumo/empyema/ring abscess) / hemorrhagic (🔴 neoplasm commonest + TB) / caseous TB → constrictive (pericardiectomy). Effusion rapid 200–300 mL → tamponade Beck (hypotension + muffled + JVD + pulsus paradoxus).

## 🎯 Heart failure cells & chronic IHD link

- LVF/mitral stenosis → pulmonary edema → hemosiderin macrophages = heart failure cells → brown induration (Item-4 Q1).
- Chronic IHD: repeated MI → diffuse subendocardial white scars + dilated hypertrophied flabby heart → ischemic cardiomyopathy 50% transplant (Item-2 Q9).

## 📌 Viva traps

1. Machinery murmur? → PDA; wide fixed split? → ASD.
2. Fish-mouth + AF + stroke? → chronic RHD MS.
3. Right-sided IE embolus? → lung; left? → brain/spleen/kidney.
4. Warty rows vs bulky friable vs tiny bland vs anywhere-warty? → rheumatic / IE / marantic / lupus.
5. Young athlete sudden death? → HCM; flabby ×3 + mural thrombus? → DCM; stiff + amyloid? → RCM.
