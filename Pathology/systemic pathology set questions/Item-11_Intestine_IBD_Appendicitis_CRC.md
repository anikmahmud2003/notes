## Q1. Name some congenital anomalies of GIT.

| Anomaly | Key features |
|---|---|
| **Atresia / stenosis / fistula** | Anywhere in GIT; feeding regurgitation at birth; 🔴 **esophageal atresia + tracheoesophageal fistula** most common pattern (blind upper pouch, fistula from lower segment to trachea); **VACTERL** association |
| **Imperforate anus** | 🔴 Most common congenital intestinal atresia — failure of cloacal diaphragm involution; screen for fistulae + other anomalies |
| **Meckel diverticulum** | 🔴 **Most common congenital GI anomaly** — failed involution of vitelline duct; antimesenteric ileum; **RULE OF 2's**: ~2% population, 2 ft from ileocecal valve, 2 inches long, 2× males, symptomatic by age 2; ectopic gastric mucosa → bleeding/pain mimicking appendicitis |
| **Hirschsprung disease** | Congenital aganglionic megacolon (see Q10); **RET mutation**; neural crest cells fail to migrate cecum→rectum → absent Meissner + Auerbach plexus → functional obstruction; **rectum ALWAYS involved**; failure to pass meconium; 10% have Down syndrome |
| **Congenital hypertrophic pyloric stenosis** | Males 3–5×; 3rd–6th week: projectile nonbilious vomiting + olive mass; myotomy curative |
| **Diaphragmatic hernia** | Left-sided viscera into chest → pulmonary hypoplasia |
| **Omphalocele vs gastroschisis** | Sac present (+ liver) vs all-layer defect without sac (intestine only) |
| **Duplications / enterogenous cysts** | Cystic/tubular duplications anywhere along GIT |
| **Ectopia (heterotopia)** | Inlet patch (esophagus), ectopic pancreas, gastric heterotopia |

> 🎯 "Congenital list = **atresia-fistula · imperforate anus · Meckel (rule of 2's) · Hirschsprung (RET) · pyloric stenosis · hernias/abdominal-wall defects · duplications/ectopia.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q2. Mention some causes of intestinal obstruction.

### Mechanical obstruction

| Level by mechanism | Causes |
|---|---|
| 🔴 **Extramural** | **Adhesions/bands** (postoperative — commonest SBO in developed world) · **External/internal hernias** (inguinal/femoral; strangulation risk) · 🔴 **Volvulus** (sigmoid > cecum; closed loop → ischemia; Asia/Africa) · Tumour mass compression |
| **Mural (in wall)** | Intussusception (ileocolic; <2 yr idiopathic, adult lead point) · Crohn/TB/ischemic/radiation strictures · Hirschsprung aganglionosis · Primary/metastatic tumours · Atresia |
| **Intraluminal** | Fecal impaction · Gallstone ileus · Ascaris bolus · Foreign body/bezoar · Barium inspissation |
| 🔴 **Functional (adynamic ileus)** | Post-laparotomy, peritonitis, hypokalemia, uremia, spinal injury, opioids/anticholinergics — NO mechanical block |
| **Vascular (strangulation ischemia)** | Volvulus/hernial strangulation — obstruction + infarction (surgical emergency) |

### Clinical pointers
Colicky pain, distension, bilious vomiting, **obstipation**; X-ray: dilated loops with **air-fluid levels ("stepladder" pattern)**.

> 🎯 "**4 mechanical causes = adhesions · hernias · volvulus · intussusception** + intraluminal/mural lesions + paralytic ileus."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q3. Define polyp. Classify polyps of intestine.

### Definition
**Polyp = any mass of tissue that projects/protrudes above the level of the mucosal surface into the intestinal lumen** — a gross descriptive term, not a histologic diagnosis.

### Classification

| Group | Types | Key points |
|---|---|---|
| **I. Non-neoplastic** | **Hyperplastic (metaplastic) polyp** | Commonest colonic polyp; left colon; serrated crypts; benign |
| | Inflammatory (pseudopoly) polyp | UC/Crohn/diverticulitis/ischemia; regenerating inflamed mucosa |
| | **Hamartomatous polyps** | **Juvenile polyp** (children; cystically dilated glands; SMAD4 if syndromic) · **Peutz-Jeghers** (STK11; arborizing smooth muscle + pigmented lips/oral mucosa) · Cowden (PTEN) |
| | Lymphoid polyp · inflammatory fibroid polyp | Reactive |
| **II. Neoplastic (premalignant)** | **Tubular adenoma** (<25% villous) | Dysplastic epithelium; malignancy risk ↑ with size >1 cm, villous component, high-grade dysplasia, sessile shape |
| | **Tubulovillous** (25–75% villous) | Intermediate risk |
| | **Villous adenoma** (>75% villous) | Highest malignant potential; secretory diarrhea/hypokalemia if large rectosigmoid |
| | **Sessile serrated lesion/polyp ± dysplasia** | Right colon; flat; **BRAF V600E + CIMP → MSI-H pathway** |
| | Traditional serrated adenoma | Distal colon, dysplastic |
| **III. Polyposis syndromes** | **FAP** (APC 5q21, AD; >100 adenomas; cancer by 40–50 yr nearly 100%; Gardner & Turcot variants) · MYH-associated polyposis (AR) · **Lynch/HNPCC** (MMR genes MLH1/MSH2/MSH6/PMS2 → MSI; right colon + endometrial Ca) · Juvenile polyposis (SMAD4/BMPR1A) · Peutz-Jeghers (STK11) · Cowden (PTEN) | Inherited predisposition |

📌 Malignant potential of an adenoma depends on: **size (>1 cm), villous architecture, high-grade dysplasia, sessile morphology**.

> 🎯 "**Non-neoplastic (hyperplastic/inflammatory/hamartomatous) vs neoplastic ADENOMA (tubular→villous, premalignant)** + polyposis syndromes (APC/MMR)."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q4. Name the inflammatory bowel diseases.

🔴 **The two classic IBDs:**
1. **Crohn disease (CD)** — segmental transmural inflammation anywhere from mouth to anus.
2. **Ulcerative colitis (UC)** — continuous mucosal inflammation starting at the rectum.
3. **Indeterminate colitis** — features overlap; cannot be classified (~10% of chronic idiopathic IBD).

📌 Related but separate entities (mention for completeness): **microscopic colitis** (lymphocytic/collagenous), diversion colitis, collagenous colitis, Behçet, ischemic/infective colitides — these are NOT true IBD.

> 🎯 "**Crohn + Ulcerative colitis (+ indeterminate colitis)** — microscopic colitis is a mimic, not classic IBD."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q5. Differentiate between inflammatory bowel disease (IBD) and IBS.

| Feature | **IBD (organic inflammation)** | **IBS (functional disorder)** |
|---|---|---|
| Nature | Chronic RELAPSING INFLAMMATORY bowel disease (Crohn/UC) with immune-genetic basis | Disorder of gut-brain interaction; 🔴 **NO structural or biochemical abnormality** |
| Pathology | Mucosal/transmural inflammation, ulcers, granulomas/crypt abscesses, strictures, fistulas | 🔴 Endoscopy AND histology completely NORMAL |
| Symptoms | Bloody diarrhea (UC), RLQ pain + weight loss (CD), fever | Abdominal pain relieved by defecation + altered bowel habit (Rome criteria ≥3 months); no blood |
| Alarm signs | Bleeding, weight loss, anemia, fever, nocturnal symptoms | Absent |
| Labs | ↑CRP/ESR, anemia, ↑fecal calprotectin, positive ANCA/pANCA (UC), ASCA (CD) | Normal labs |
| Complications | Strictures, fistulas, abscess, toxic megacolon, colorectal carcinoma | None — normal life expectancy |
| Treatment | 5-ASA, corticosteroids, azathioprine, anti-TNF, surgery | Diet (low-FODMAP), fiber, antispasmodics, TCAs, 5-HT modulators |

> 🎯 "**IBD = visible inflammation + alarm signs + complications; IBS = Rome criteria pain with COMPLETELY normal endoscopy/histology/labs.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q6. Mention important features of Crohn's disease.

### Definition
**Crohn disease = a chronic relapsing-remitting, TRANSMURAL, segmental (skip-lesion) granulomatous inflammatory bowel disease that may affect ANY part of the GIT from mouth to anus, most often the terminal ileum.**

### Important features
| Aspect | Features |
|---|---|
| Epidemiology | Young adults 15–35 yr; Jews > whites; 🔴 **smoking INCREASES risk/worsens course**; genes: **NOD2/CARD15, ATG16L1, IL23R**; Th1/Th17 cytokines |
| Distribution | Anywhere mouth→anus; 🔴 terminal ileum ± right colon most common; **SKIP LESIONS** (normal segments between diseased); rectum often spared |
| Gross | Aphthous ulcers → serpentine linear ulcers → 🔴 **COBBLESTONE mucosa**; thick rigid wall (**string sign** on barium); 🔴 **CREeping FAT** wrapping serosa; fissures, fistulas, strictures; mesenteric nodes enlarged |
| Microscopy | 🔴 **TRANSMURAL inflammation**; 🔴 **NONCASEATING GRANULOMAS (~35%)**; fissuring ulcers; lymphoid aggregates; neural hyperplasia |
| Clinical | RLQ pain (mimics appendicitis), chronic diarrhea (usually NON-bloody), weight loss, fever, malaise; perianal disease/fistulae; malabsorption (ileum → B12 deficiency, gallstones, oxalate renal stones) |
| Extraintestinal | Arthritis/sacroiliitis, uveitis, erythema nodosum, pyoderma gangrenosum, primary sclerosing cholangitis (less than UC) |
| Complications | Stricture → obstruction, 🔴 fistulas (entero-enteric, entero-vesical, entero-cutaneous, perianal), intra-abdominal abscess, perforation, malabsorption/gallstones, **colorectal cancer risk** (long-standing colonic disease), amyloidosis |
| Treatment | Steroids, immunomodulators, 🔴 **anti-TNF agents**, surgery for complications (recurs after resection) |

> 🎯 "**Skip + transmural + noncaseating granuloma + cobblestone + creeping fat + FISTULAS** · smoker worsens · NOD2."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q7. Differentiate between Crohn's disease and ulcerative colitis.

| Feature | **Crohn disease** | **Ulcerative colitis** |
|---|---|---|
| Site | Mouth → anus; 🔴 **terminal ileum most affected**; rectum usually spared | 🔴 Colon only; **rectum ALWAYS involved**, extends proximally CONTINUOUSLY |
| Pattern | 🔴 Segmental **SKIP lesions** | Continuous, no skips |
| Depth | 🔴 **TRANSWALL (full-thickness)** | 🔴 **Mucosa + submucosa only** |
| Gross | Aphthous → linear/serpentine ulcers, 🔴 cobblestone, thick wall, stricture, fistula, **creeping fat** | Diffuse erythema, friable granular mucosa, continuous superficial ulceration, 🔴 **PSEUDOPOLYPS**, no strictures/fistulas |
| Microscopy | Noncaseating **granulomas (~35%)**, transmural lymphoid aggregates, fissures | 🔴 **Crypt abscesses**, crypt distortion/architectural distortion, goblet-cell depletion, basal plasmacytosis |
| Diarrhea | Usually non-bloody, watery | 🔴 **Bloody diarrhea + mucus + tenesmus** |
| Pain site | RLQ | LLQ/left-sided cramps |
| Fistulas/strictures/perianal disease | 🔴 Common | Rare/absent |
| Toxic megacolon | Uncommon | 🔴 Classic complication (>6 cm dilation, transmural) |
| Smoking | Worsens (↑risk) | 🔴 Protective; cessation may trigger onset |
| Serology | ASCA+ | pANCA+ |
| Genes | NOD2/CARD15, ATG16L1, IL23R | HLA associations, IL-10/IL23R; Th2-like (IL-13) |
| Cancer risk | ↑ (long-standing extensive colitis) | 🔴 Higher (pancolitis after 8–10 yr → surveillance colonoscopy) |
| Surgery | Not curative — recurrence at anastomosis | 🔴 **Colectomy is CURATIVE** (removes diseased organ) |

> 🎯 "**Crohn SKIPS, UC never stops** · transmural/granuloma/fistula/smoker vs mucosal/crypt abscess/pseudopolyp/bloody/toxic megacolon."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q8. Name some ulcers of GIT / stomach / intestine.

| Ulcer | Characteristic feature |
|---|---|
| **Peptic ulcer (gastric/duodenal)** | Punched-out, ≥5 mm, breaches muscularis mucosae; 4-layer floor (exudate→PMN→granulation→scar) |
| **Stress ulcers** | Multiple superficial erosions in ICU settings: 🔴 **Curling (burns), Cushing (CNS trauma/surgery)**, sepsis/shock |
| **NSAID-induced ulcers** | Gastric antrum; multiple shallow erosions ± silent bleeding |
| **Barrett ulcer** | Distal esophagus within columnar metaplasia |
| **Mallory-Weiss tears** | Longitudinal mucosal tears at GEJ after vomiting |
| **Meckel diverticular ulcer** | Acid from ectopic gastric mucosa → adjacent ileal ulceration (bleeding in children) |
| **Typhoid (enteric fever) ulcer** | 🔴 Ileocecal region; **LONGITUDINAL oval ulcers along lymphoid follicles (Peyer patches)** → perforation in 3rd week (*Salmonella typhi*) |
| **Tuberculous ulcer** | 🔴 Ileocecal; **TRANSVERSE/circumferential ("girdle") ulcers**, transverse to bowel axis (TB lymphangitis); strictures |
| **Amoebic ulcer** | 🔴 **Flask-shaped (bottle-necked) ulcers**, undermining edges, skip lesions in colon (*Entamoeba histolytica*); trophozoites with ingested RBCs |
| **Bacillary dysentery (Shigella)** | Superficial diffuse mucosal erosions/pseudomembrane of colon |
| **Ischemic colitis ulceration** | Watershed zones (splenic flexure, rectosigmoid); longitudinal ulceration → stricture |
| **Crohn aphthous/linear fissuring ulcers** | Skip lesions, serpentine → cobblestone |
| **Ulcerative colitis** | Continuous superficial collar-button ulcers, pseudopolyps |
| **Malignant ulcers** | Ulcerated gastric/colonic carcinoma (heaped margins), lymphoma ulcers, melanoma metastases |
| **Zollinger-Ellison jejunal ulcers** | Multiple distal (jejunal) refractory peptic ulcers |

> 🎯 "Direction clues: **typhoid = LONGITUDINAL, TB = TRANSVERSE, amoebic = FLASK-shaped, peptic = PUNCHED-out, stress = Curling/Cushing.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q9. Classify tumours of intestine.

| Category | Small intestine | Large intestine (colon/rectum) |
|---|---|---|
| **Epithelial — benign** | Adenoma (duodenum/ampulla), Brunner-gland hamartoma, Peutz-Jeghers/juvenile hamartomas | Hyperplastic polyp, inflammatory polyp, hamartomatous polyps, sessile serrated lesion, **adenomas** (tubular/villous/tubulovillous) |

## Q10. Short note on: GIST, Hirschsprung disease, Pseudomyxoma peritonei.

### (a) GIST — Gastrointestinal Stromal Tumour
**Definition: the most common MESENCHYMAL (stromal) neoplasm of the GI tract, arising from interstitial cells of Cajal (pacemaker cells), showing KIT (CD117) or DOG1 expression.**
- **Sites:** stomach (~60%) > small intestine > colon/rectum, esophagus; also omentum/mesentery.
- **Molecular:** 🔴 activating **KIT (c-KIT/CD117) mutation (~75–80%)** or **PDGFRA mutation (~8%)** → constitutive tyrosine-kinase signalling; SDH-deficient subset in children/carney triad context.
- **Gross:** submucosal/extrinsic mass covered by intact mucosa (central ulceration → bleeding); whorled fleshy tan cut surface ± hemorrhage/necrosis.
- **Micro:** fascicles of spindle cells (or epithelioid variant); IHC: **CD117/KIT+, DOG1+, CD34+, SMA variable; S100 negative**.
- 🔴 **Behaviour graded (NOT benign/malignant binary): size + mitotic count predict metastasis** (liver/peritoneum); lymphatics rare.
- **Treatment:** surgical resection; unresectable/metastatic → 🔴 **imatinib (tyrosine kinase inhibitor)** — landmark targeted therapy.

> 🎯 "**GIST = Cajal cell tumour, KIT/DOG1+, imatinib-responsive; behaviour = size + mitoses.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

---

### (b) Hirschsprung disease
**Definition: congenital aganglionic megacolon — absence of ganglion cells of BOTH the Meissner (submucosal) and Auerbach (myenteric) plexuses in a segment of colon due to arrest of neural-crest cell migration, causing functional obstruction.**
- **Genetics:** 🔴 loss-of-function **RET mutations** (majority familial cases); EDNRB/EDN3 ligand-receptor pair; **~10% associated with Down syndrome**.
- **Pathogenesis chain:**
```
Neural crest cells fail to migrate/die prematurely (craniocaudal)
   → aganglionic distal segment (RECTUM always; short vs long segment)
   → absent peristalsis + unrelaxed internal sphincter
   → functional obstruction
   → massive dilation + hypertrophy of PROXIMAL normally-innervated colon
```
- **Clinical:** neonate fails to pass meconium within 48 h; abdominal distension, bilious vomiting; older children — chronic constipation; threats = 🔴 **enterocolitis, perforation, fluid-electrolyte disturbance**.
- **Diagnosis:** suction rectal biopsy — 🔴 absence of ganglion cells + **hypertrophied nerve trunks; acetylcholinesterase histochemistry highlights excess AChE fibres**; frozen sections at pull-through.
- **Treatment:** resection of aganglionic segment (pull-through procedures). Acquired megacolon mimics: Chagas disease, strictures, UC.

> 🎯 "**No ganglion cells (Meissner+Auerbach) in RECTUM → no meconium; RET gene; AChE stain confirms.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

---

### (c) Pseudomyxoma peritonei
**Definition: accumulation of copious gelatinous/mucinous ascites with implants of mucinous epithelium on the peritoneal surfaces, producing progressive 'jelly belly' distension.**
- 🔴 **Source: rupture (or transmural spread) of a low-grade appendiceal mucinous neoplasm (LAMN)** in most cases; occasionally ovarian mucinous tumours (GI-type should raise suspicion of occult appendiceal primary).
- Cells line the peritoneum as strips/nests floating in extracellular mucin; **no true invasion required** for the clinical picture.
- Behaviour: slowly progressive, recurs relentlessly; causes bowel obstruction, malnutrition; rarely distant metastasis.
- **Treatment:** cytoreductive surgery + 🔴 **hyperthermic intraperitoneal chemotherapy (HIPEC)**.

> 🎯 "**Appendiceal mucinous neoplasm ruptures → jelly belly → debulk + HIPEC.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q11. Etiopathogenesis of acute appendicitis.

### Definition
**Acute appendicitis = acute transmural inflammation of the appendix, almost always initiated by luminal OBSTRUCTION, culminating in bacterial invasion, ischemic necrosis and possible perforation — the most common cause of the acute abdomen requiring surgery.**

### Etiopathogenesis
```
LUMINAL OBSTRUCTION
   • FECALITH (inspissated stool) — most common in adults
   • LYMPHOID HYPERPLASIA (viral infection/Yersinia) — most common in children
   • Foreign body, fruit seeds, parasites (Enterobius vermicularis)
   • Tumour (carcinoid/mucinous neoplasm) — rare lead point
        ↓
Continued mucus secretion into closed lumen
        ↓
↑ Intraluminal pressure → venous congestion → mural ISCHEMIA
        ↓
Loss of mucosal integrity → BACTERIAL INVASION
(E. coli, Bacteroides fragilis, Peptostreptococcus, Pseudomonas)
        ↓
ACUTE TRANSWALL INFLAMMATION (neutrophils throughout wall)
        ↓
Suppurative → gangrenous (necrosis) → PERFORATION
        ↓
Localized periappendicular abscess OR generalized PERITONITIS
```

📌 Supporting factors: low-fiber diet (fecalith formation), family history; peak age 10–30 yr.

> 🎯 "**Obstruction (fecalith/lymphoid hyperplasia) → pressure → ischemia → bacteria → necrosis → perforation.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q12. Complications of acute appendicitis.

| Complication | Mechanism/features |
|---|---|
| 🔴 **Perforation** | Necrosis of wall (esp. fecalith impaction, old/young patients); incidence rises after 48 h |
| 🔴 **Periappendicular (localized) abscess** | Omentum + adjacent bowel wall off the perforation → tender RLQ mass; drain ± interval appendectomy |
| 🔴 **Generalized peritonitis** | Free perforation → fibrinopurulent exudate throughout peritoneal cavity → shock, ileus, sepsis |
| 🔴 **Portal pyemia / pylephlebitis** | Septic thrombophlebitis of portal vein → 🔴 **multiple liver abscesses**, jaundice, high spiking fever |
| Septicaemia/septic shock | In neglected cases |
| **Adhesive intestinal obstruction** | Late — post-appendicitis/peritonitis fibrous bands |
| **Infertility (females)** | Peritoneal/pelvic inflammation → tubal scarring |
| Wound infection | Postoperative |
| **Recurrent/chronic appendicitis** | Recurrent milder attacks; fibrotic obliterated lumen with chronic infiltrate |
| Stump appendicitis | After incomplete appendectomy (rare) |

> 🎯 "**Perforate → abscess or peritonitis → pylephlebitis → liver abscess**; late = adhesions, tubal infertility."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q14. What do you mean by IBS & IBD? Give the difference between IBS & IBD.

### Definitions
- 🔴 **IBS (irritable bowel syndrome)** = a **chronic FUNCTIONAL disorder of gut-brain interaction** characterized by recurrent abdominal pain related to defecation with altered bowel frequency/form (**Rome criteria**, ≥3 months) **without any demonstrable structural, inflammatory or biochemical abnormality**.
- 🔴 **IBD (inflammatory bowel disease)** = a group of **chronic idiopathic IMMUNE-mediated INFLAMMATORY diseases of the GIT** — principally **Crohn disease and ulcerative colitis** — with documented structural pathology (transmural/mucosal inflammation, ulcers, granulomas, crypt abscesses).

### Differences

| Feature | **IBS** | **IBD** |
|---|---|---|
| Nature | Functional (visceral hypersensitivity, motility, psychosocial, post-infectious) | Organic autoimmune-inflammatory (genetics NOD2/HLA, microbiome, environment) |
| Inflammation/pathology | 🔴 NONE — endoscopy, biopsy, imaging NORMAL | 🔴 Present — skip/transmural (CD) or continuous mucosal (UC) lesions |
| Age/sex | Young adults, female predominance | Bimodal 15–35 yr, both sexes |
| Pain | Periumbilical/LLQ, relieved by defecation, never wakes patient | Localized (RLQ CD / LLQ UC), night pain possible |
| Stool | Mucus ± alternating constipation/diarrhea; **NO blood** | 🔴 Blood + mucus (UC), steatorrhea (CD) |
| Systemic features | Absent (no fever, no weight loss) | Fever, weight loss, anemia, ↑ESR/CRP, ↑fecal calprotectin |
| Complications | None | Stricture, fistula, abscess, toxic megacolon, perforation, **colorectal cancer** |
| Diagnosis | Rome criteria + exclusion (normal labs/endoscopy) | Colonoscopy + biopsy, MR/CT enterography, serology (ASCA/pANCA) |
| Treatment | Reassurance, low-FODMAP diet, fiber, antispasmodics, TCAs, 5-HT3/4 modulators | 5-ASA, steroids, thiopurines, methotrexate, anti-TNF/anti-integrin/anti-IL-12/23 biologics, surgery |

> 🎯 "**IBS = symptoms WITHOUT pathology; IBD = pathology WITH consequences.** Calprotectin high ⇒ think IBD."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q15. What are risk factor /predisposing factor for Colorectal carcinoma? Give the pathogenesis of colorectal carcinoma.

### Risk factors

| Category | Factors |
|---|---|
| **Age/demography** | >50 yr (rising in younger adults); male slightly > female; developed-world diet |
| 🔴 **Dietary/lifestyle** | Red/processed meat, low fiber, refined carbohydrates; obesity; sedentary life; smoking; alcohol |
| **Personal history** | Previous colorectal adenoma/carcinoma · long-standing 🔴 **IBD (UC/Crohn colitis — surveillance after 8–10 yr)** · radiation exposure · diabetes/acromegaly |
| 🔴 **Hereditary syndromes** | **FAP** (APC germline; 100% cancer by 40–50 yr unless prophylactic colectomy) · **Lynch/HNPCC** (MLH1/MSH2/MSH6/PMS2 → MSI) · MAP (MYH) · Peutz-Jeghers, juvenile polyposis |
| **Protective factors** | Fiber, fruits/vegetables, calcium, vitamin D, aspirin/NSAIDs (COX inhibition) |

### Pathogenesis — two molecular pathways

**A. APC/β-catenin (chromosomal instability) pathway — adenoma-carcinoma sequence (classic):**
```
NORMAL epithelium
   → APC loss (5q21) [initiating event; FAP = germline]
      → β-catenin accumulates → ↑MYC, cyclin D1 → proliferation → EARLY ADENOMA
   → KRAS activation (12p) → growth autonomy → LATE/LARGE ADENOMA
   → loss of SMAD2/SMAD4 (18q) (TGF-β pathway) → LATE ADENOMA with high-grade dysplasia
   → TP53 loss (17p) → CARCINOMA
   → further changes → METASTASIS
```
(Left colon, napkin-ring/annular stenosing tumours.)

**B. MSI (microsatellite instability) pathway — mismatch repair defect:**
```
Defective DNA mismatch repair
   • LYNCH: germline MLH1/MSH2/MSH6/PMS2 + second-hit loss
   • Sporadic: MLH1 promoter METHYLATION (CIMP-high) ± BRAF V600E
        → frameshift mutations accumulate (TGFBR2, BAX) → MSI-HIGH carcinoma
```
(Right/proximal colon, bulky mucinous tumours, better prognosis.)

### Morphology correlation
Right colon — fungating/bulky exophytic masses (wide lumen, liquid stool → late obstruction, iron-deficiency anemia); left colon — annular constricting "**napkin-ring**" lesions (solid stool → early obstruction, altered habit, bleeding); microscopy: adenocarcinoma forming glands ± mucin/signet-ring.

> 🎯 "**APC → KRAS → SMAD2/4 → TP53** (left, chromosomal) vs **MMR-loss/MSI-H ± BRAF+CIMP** (right, Lynch-like) — plus FAP/Lynch/IBD/red-meat risks."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q16. Problem-based question: A man presented with acute abdominal pain, vomiting, and fever. On examination, tenderness was observed in the right iliac fossa. Blood picture shows neutrophilic leukocytosis. (a) What is your diagnosis? (b) What are the possible etiologies and complications? (c) After operation, what do you expect in the histopathology?

### (a) Diagnosis
🔴 **Acute appendicitis** (acute suppurative appendicitis).
Supporting points:
- **Periumbilical pain shifting to RIGHT ILIAC FOSSA (McBurney point)** — classic migratory pain (visceral → parietal).
- Anorexia, nausea/vomiting, **fever (low grade)**.
- 🔴 **Neutrophilic leukocytosis (12,000–20,000/µL)** with left shift.
- Differential to mention briefly: mesenteric adenitis (Yersinia), Meckel diverticulitis, Crohn disease, ectopic pregnancy/ovarian torsion (female), right ureteric calculus, perforated peptic ulcer, typhoid ileitis.

### (b) Possible etiologies
1. 🔴 **Obstruction of the appendiceal lumen:**
   - **Fecolith/appendlith** (most common in adults);
   - **Lymphoid follicular hyperplasia** (children — post-viral/Yersinia);
   - Foreign body, fruit seeds, **Enterobius vermicularis**;
   - Neoplasm (carcinoid, LAMN) as lead point;
   - Kinking/adhesions, low-fiber diet predisposing to fecalith.
2. Obstruction → mucus retention → ↑intraluminal pressure → venous compromise → **ischemia** → **bacterial proliferation** (*E. coli, Bacteroides, Peptostreptococcus*) → acute transmural suppurative inflammation.

### Complications
| Complication | Note |
|---|---|
| 🔴 **Perforation** (esp. >48 h, extremes of age) | → localized **periappendicular abscess** or **generalized peritonitis** |
| 🔴 **Portal pylephlebitis** | Septic portal-vein thrombophlebitis → **multiple pyemic liver abscesses** |
| Septicaemia/shock | Neglected gangrenous appendix |
| Adhesions → intestinal obstruction | Late sequela of peritonitis |
| Tubal scarring → infertility | Females |
| Wound infection, recurrent/chronic appendicitis | Postoperative/clinical courses |

### (c) Expected histopathology of the resected appendix
- 🔴 **Acute suppurative (transmural) appendicitis:**
  - **Neutrophilic infiltration** — dense PMNs throughout **all coats**: mucosa (with cryptitis/crypt microabscesses) → lamina propria → muscularis → serosa.
  - **Mucosal ulceration/fibrino-purulent exudate** on the luminal surface.
  - Congestion, edema, dilated engorged vessels; focal **hemorrhage**.
  - **Fecolith/inspissated faecal material ± Enterobius** in the lumen; lumen may contain pus.
- If advanced: **gangrenous appendicitis** — coagulative necrosis of wall, thrombosed vessels, serosal **fibrino-purulent (acute) serositis**; perforation site with acute peritonitic exudate.
- Chronic changes (recurrent attacks): fibrosis, chronic inflammatory cells, obliteration of lumen.
- 🔴 Report should also note **absence of neoplasia** (exclude incidental carcinoid at tip).

> 🎯 "PBQ triad: **RLQ tenderness + fever + neutrophilia = acute appendicitis** → histo says *neutrophils through ALL layers ± fecolith ± gangrene*."
