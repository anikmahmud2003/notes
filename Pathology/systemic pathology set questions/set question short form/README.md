# Systemic Pathology — Item Set 1–26 · Short-Form Flashcards

> 🎯 **Short-form toggle flashcards** — split from the big/compound questions into
> **small, one-point-at-a-time Q→A cards**. Same content, same Robbins 10e + Arif 15e citations,
> just broken into digestible short questions (e.g. Berry aneurysm → *Definition* /
> *Most common site* / *Associations* / *Clinical importance* as separate cards).

## How each card works

- One `<details>` toggle = **one short question** (click → reveal its answer).
- Naming: the item's Q-number keeps its position (`Q1`, `Q2` …), sub-parts get a letter
  (`Q1a`, `Q1b`, …); where a single section was further split (e.g. Berry aneurysm) you may
  see `Q1ba`, `Q1bb`, … each labelled with its exact sub-topic.
- Every original answer is fully preserved — nothing is removed or summarised.
