## Q1. Name some congenital or acquired anomalies of GIT.

### Congenital anomalies

| Anomaly | Key features |
|---|---|
| **Atresia / fistula / duplication** | Anywhere in GIT; regurgitation at first feed; **esophageal atresia + tracheoesophageal fistula** (near tracheal bifurcation); part of **VACTERL** association; **imperforate anus** = most common congenital intestinal atresia (cloacal diaphragm failure) |
| **Diaphragmatic hernia** | Incomplete diaphragm → viscera into thorax (**left side most common**) → pulmonary hypoplasia |
| **Omphalocele** | Herniated gut (+ liver) covered by a sac of amnion/peritoneum/Wharton jelly; other defects + chromosomal abnormalities |
| **Gastroschisis** | Defect through ALL abdominal-wall layers; intestine only, **no sac**; isolated defect, incidence rising |
| **Ectopia (heterotopia)** | 🔴 Most common site = ectopic gastric mucosa in upper esophagus (**inlet patch**); ectopic pancreas; gastric heterotopia in Meckel |
| **Meckel diverticulum** | 🔴 **Most common congenital GI anomaly**; vitelline duct remnant; antimesenteric ileum; **rule of 2's** (2% population, 2 ft from ileocecal valve, 2 inches long, 2× males, symptomatic by age 2) |
| **Congenital hypertrophic pyloric stenosis** | Males 3–5×; presents **3rd–6th week**: projectile **NONBILIOUS** vomiting + **olive-shaped mass**; muscularis hyperplasia; myotomy curative |
| **Hirschsprung disease** | Congenital aganglionic megacolon; **RET mutations**; neural-crest migration arrest → absent Auerbach + Meissner plexus; **rectum ALWAYS affected**; failure to pass meconium |

### Acquired anomalies
- **Strictures** — chronic GERD, caustic ingestion, radiation, systemic sclerosis.
- **Hiatal hernia** (sliding > paraesophageal).
- **Diverticular disease** of colon (pseudodiverticula at vasa recta weak points).
- **Adhesions/hernias** → obstruction; acquired pyloric stenosis (post-ulcer/gastric-cancer scarring).
- **Acquired megacolon** — Chagas disease, strictures, UC.

> 🎯 "Congenital 6: **atresia-fistula · hernia · omphalocele-gastroschisis · ectopia · Meckel (2's) · pyloric stenosis · Hirschsprung**."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q2. Classify neoplasms of stomach / GIT.

### Neoplasms of the GIT by region

| Region | Benign | Malignant |
|---|---|---|
| **Esophagus** | Leiomyoma (most common benign) | SCC (middle third) · Adenocarcinoma (distal, Barrett) |
| **Stomach** | Hyperplastic/inflammatory polyp · Fundic gland polyp · Adenoma | 🔴 **Adenocarcinoma (90%)** — intestinal/diffuse · **MALT lymphoma** · Neuroendocrine (carcinoid) tumour · **GIST** |
| **Small intestine** | Adenoma, leiomyoma, lipoma, Brunner-gland hamartoma | 🔴 **Carcinoid (NET)** — most common SI malignancy · Adenocarcinoma (duodenum/ampulla) · Lymphoma (MALT/DLBCL) · GIST |
| **Colon & rectum** | Hyperplastic polyp · Hamartomatous (juvenile, Peutz-Jeghers) · Sessile serrated lesion · Adenoma (tubular/villous/tubulovillous) | 🔴 **Colorectal adenocarcinoma** · Carcinoid · Lymphoma · GIST |
| **Anal canal** | Condyloma acuminatum | **SCC** (HPV 16/18), basaloid/cloacogenic variant · Melanoma |

### Stomach — detailed classification

| Category | Types |
|---|---|
| **Epithelial — benign** | Inflammatory/hyperplastic polyps (75% of gastric polyps, antrum) · Fundic gland polyps (PPI/FAP) · Gastric adenomas (~30% malignant potential, antral villous) |
| **Epithelial — malignant** | **Adenocarcinoma:** Lauren — **intestinal type** vs **diffuse type** (signet-ring, linitis plastica) · Borrmann I–IV gross types · Early vs advanced |
| **Lymphoma** | **Extranodal marginal-zone (MALT) lymphoma** — H. pylori-driven, t(11;18) BIRC3-MALT1; DLBCL |
| **Neuroendocrine tumours** | Type I (autoimmune gastritis, benign) · Type II (MEN1/ZES) · Type III (sporadic, aggressive) |
| **Mesenchymal** | 🔴 **GIST** (KIT/CD117+, imatinib-sensitive — most common mesenchymal tumour) · leiomyoma, schwannoma |
| **Metastatic** | Breast (lobular), melanoma, lung |

> 🎯 "GIT neoplasms = **epithelial (polyp→carcinoma) + lymphoma + neuroendocrine + mesenchymal GIST**; stomach: adenoCa 90% + MALToma + carcinoid + GIST."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q3. Define gastritis and mention its types and causes.

### Definition
**Gastritis = inflammation of the gastric mucosa, diagnosed histologically by the presence of inflammatory cells (neutrophils and/or mononuclear cells) within the mucosa.**
📌 Distinguish from **gastropathy** = epithelial injury with regeneration but NO significant inflammation (NSAIDs, alcohol, ischemia).

### Classification with causes

| Type | Subtypes | Causes |
|---|---|---|
| **Acute (erosive/hemorrhagic) gastritis** | Acute erosive · Stress ulcers | 🔴 **NSAIDs/aspirin** (COX inhibition), alcohol, corrosives, heavy smoking, chemotherapy; stress: **Curling ulcer (burns), Cushing ulcer (CNS trauma/surgery)**; shock/sepsis/ischemia |
| **Chronic gastritis** | 🔴 **Type B — H. pylori-associated (most common ~90%)** | *Helicobacter pylori* colonization of antrum |
| | **Type A — Autoimmune atrophic gastritis** | 🔴 **Anti-parietal-cell + anti-intrinsic-factor antibodies** → body/fundus atrophy, achlorhydria, hypergastrinemia, **pernicious anemia**, ↑ cancer/carcinoid risk |
| **Special/uncommon forms** | Reactive gastropathy | Bile reflux, NSAIDs — foveolar hyperplasia without inflammation |
| | Lymphocytic gastritis | Celiac disease-associated; intraepithelial T lymphocytes |
| | Eosinophilic gastritis | Food allergy/parasites |
| | Granulomatous gastritis | Crohn disease, sarcoidosis, TB, Wegener |
| | Radiation, CMV (immunocompromised), graft-versus-host disease | Treatment/immunosuppression contexts |
| **Hypertrophic gastropathies** | **Ménétrier disease** | ↑TGF-α → giant rugae, foveolar hyperplasia, protein loss (hypoalbuminemia) |
| | **Zollinger-Ellison syndrome** | Gastrinoma → acid hypersecretion → refractory ulcers (gastrin >1000 pg/mL) |

> 🎯 "**Acute (NSAID/alcohol/stress-Curling-Cushing) vs Chronic (B = H. pylori commonest, A = autoimmune pernicious anemia)** + special forms."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q4. Define peptic ulcer and mention its sites of formation.

### Definition
**Peptic ulcer = a chronic, usually solitary, breach of the gastrointestinal mucosa ≥5 mm in diameter that extends through the muscularis mucosae into the submucosa (deeper layers may be involved), caused by the action of acid-peptic juice.**

### Sites of formation

| Site | Frequency/features |
|---|---|
| 🔴 **Duodenum — first part (duodenal bulb)** | **Most common site**; H. pylori 80–95%; acid high; **never malignant** |
| 🔴 **Stomach — antrum and lesser curvature** | H. pylori 50–60% + NSAIDs; **up to 10% may be malignant — always biopsy** |
| **Distal esophagus** (Barrett/reflux) | Acid reflux injury |
| **Gastroenterostomy stoma** | After surgery (marginal ulcer) |
| **Jejunum** | Only in **Zollinger-Ellison syndrome** (gastrinoma) — ectopic sites |
| **Meckel diverticulum** | Ulcers on adjacent mucosa from **ectopic gastric mucosa** |

📌 Duodenal : gastric ratio ≈ **3–4 : 1** in most series.

> 🎯 "**Ulcer ≥5 mm breaching muscularis mucosae** · sites: duodenal bulb #1 → antrum/lesser curvature → GEJ → stoma → jejunum (ZES) → Meckel."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q5. Mention the defence mechanism of gastric mucosa.

The stomach balances **aggressive factors (acid + pepsin)** against **defensive (mucosal protective) mechanisms**:

| Layer | Defence mechanism |
|---|---|
| **Pre-epithelial** | 🔴 **Mucus layer** (viscous gel trapping bicarbonate → pH gradient) · surface hydrophobicity (phospholipids) |
| **Epithelial** | 🔴 Tight junctions between surface mucous cells · **rapid cell turnover/restitution** (re-epithelialization within hours after injury) · HCO₃⁻ secretion by epithelium |
| **Microvascular** | 🔴 **Mucosal blood flow** washes back-diffused H⁺ away, delivers O₂/nutrients/bicarbonate for repair |
| **Biochemical** | 🔴 **Prostaglandins (PGE₂, PGI₂ via COX-1)** stimulate mucus + bicarbonate secretion, maintain blood flow, inhibit acid — the mechanism NSAIDs sabotage |
| **Growth/repair factors** | Epidermal growth factor, TGF-α, trefoil peptides promote healing |
| **Immune** | Mucosa-associated lymphoid tissue; clearance of pathogens |

```
Defence < Aggression  →  ulceration
NSAID ↓PG · H. pylori ↓mucus/↑acid · smoking ↓bicarbonate/flow
   → breach of barrier → back-diffusion of H+ → erosion → ULCER
```

> 🎯 "**Mucus-bicarbonate barrier + prostaglandins + blood flow + restitution** = the four pillars NSAIDs and H. pylori knock down."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q6. Describe the pathogenesis of peptic ulcer disease.

### Concept
PUD results when 🔴 **aggressive factors (acid–pepsin, H. pylori toxins, NSAIDs, bile)** overwhelm 🔴 **mucosal defence (mucus-bicarbonate, PGs, blood flow, restitution)**. Two dominant pathways account for almost all cases:

### Pathway 1 — H. pylori (most important)
```
H. pylori colonizes antral mucosa (urease neutralizes acid,
   flagella burrow through mucus, BabA adhesin attaches)
   → CagA + VacA toxins injure epithelium
   → chronic active (antral) gastritis
   → somatostatin (D-cell) release ↓ → gastrin (G-cell) ↑
   → parietal-cell acid hypersecretion
   → acid load hits duodenum → gastric metaplasia of duodenal bulb
   → H. pylori colonizes metaplastic islands + inflammation
   → mucus depletion, impaired bicarbonate & blood flow
   → MUCOSAL BREAK → PEPTIC ULCER
```

### Pathway 2 — NSAIDs
```
NSAID inhibits COX-1
   → ↓ Prostaglandin (PGE₂/PGI₂)
   → ↓ mucus & bicarbonate secretion + ↓ mucosal blood flow
   + direct topical (acidic) epithelial toxicity
   → barrier failure → H+ back-diffusion → erosion → ULCER
```

### Supporting/aggravating factors
- **Smoking:** ↓ bicarbonate, ↑ acid, delays healing.
- **Steroids + NSAIDs together** multiply risk; **gastrinoma (ZES)** → massive acid → refractory jejunal ulcers.
- 📌 **Duodenal ulcers = high-acid phenotype (H. pylori-driven hypersecretion); gastric ulcers = weakened defences with normal/low acid.**

> 🎯 "**Ulcer = aggression beats defence** · H. pylori route (urease→CagA→↑gastrin→↑acid) + NSAID route (↓PG↓barrier)."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q7. Mention causes, risk factors, and predisposing factors of peptic ulcer disease.

| Category | Factors |
|---|---|
| 🔴 **Major causes** | **Helicobacter pylori infection** (duodenal 80–95%, gastric 50–60%) · **NSAIDs/aspirin** (COX-1 inhibition) |
| **Hypersecretory states** | **Zollinger-Ellison syndrome (gastrinoma)** · mastocytosis, antral G-cell hyperplasia · Cushing ulcer (CNS trauma → vagal acid surge) |
| **Lifestyle/environment** | 🔴 **Cigarette smoking** (↓bicarbonate, impairs healing) · alcohol (mucosal irritant) · psychological stress · coffee (weak evidence) |
| **Drugs** | Glucocorticoids (especially combined with NSAIDs) · potassium chloride, iron, bisphosphonates (direct injury) |
| **Genetic/host** | Family history · **blood group O** (duodenal ulcer) · non-secretor status |
| **Systemic diseases** | Cirrhosis, COPD, chronic renal failure, hyperparathyroidism (↑calcium→↑acid) · critical illness — **stress-related mucosal injury: Curling ulcer (burns), Cushing ulcer (head injury/neurosurgery), sepsis/shock** |
| **Protective paradox** | Gastric cancer risk ↓ in DU patients; some H. pylori strains protect against esophageal adenocarcinoma |

> 🎯 "**H. pylori + NSAID = the two big ones**; add smoking, ZES, steroids, blood group O, Curling/Cushing stress ulcers."

## Q8. List the diseases of stomach caused by H. pylori.

🔴 *H. pylori* (WHO class I carcinogen) produces a spectrum in the stomach:

```
Acute H. pylori gastritis
   → CHRONIC ACTIVE ANTRAL GASTRITIS (90% of chronic gastritis)
        ↳ PEPTIC ULCER (gastric type)
        ↳ GASTRIC ADENOCARCINOMA — INTESTINAL TYPE (risk ↑5–9×;
              gastritis → atrophy → intestinal metaplasia → dysplasia → carcinoma)
        ↳ EXTRANODAL MARGINAL-ZONE B-CELL LYMPHOMA OF MALT
              (eradication of H. pylori cures 60–70% of low-grade cases)
        ↳ HYPERPLASTIC (inflammatory) POLYPS — reactive background
```

| Disease | Link strength |
|---|---|
| **Chronic antral gastritis** | Direct causative agent (most common cause worldwide) |
| **Peptic ulcer — gastric** | 50–60% attributable |
| **Gastric adenocarcinoma (intestinal type)** | 🔴 Class I carcinogen; strongest with atrophy/metaplasia |
| **Gastric MALT lymphoma** | 🔴 Antigen (H. pylori)-driven; t(11;18) |
| (Bonus) | Protective against Barrett/esophageal adenocarcinoma (hypochlorhydria) — mention as exam pearl |

> 🎯 "H. pylori = **gastritis → GU → intestinal-type adenoCa + MALToma** ('one bug, four diseases')."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q9. Explain the role of H. pylori in the pathogenesis of peptic ulcer.

### Step-by-step virulence → ulcer

| Step | Mechanism |
|---|---|
| **Survival in acid** | 🔴 **Urease** splits urea → NH₃ + CO₂ → buffers gastric acid around the organism; also basis of urea breath test/CLO test |
| **Colonization** | Spiral shape + **flagella** propel through mucus; **adhesins (BabA, SabA)** bind Lewis antigens on surface mucous cells of the **antrum** |
| **Epithelial injury** | **VacA** vacuolating cytotoxin damages epithelium; 🔴 **CagA** (cag pathogenicity island) injected into cells (type IV secretion system) → altered junctions/signalling → IL-8 driven inflammation |
| **Inflammation** | Neutrophils ("active") + mononuclear infiltrate → cytokines (IL-1β, TNF, IFN-γ) → epithelial apoptosis, mucus depletion |
| **Acid dysregulation** | Inflammation destroys **somatostatin-secreting D cells** → disinhibited **G cells → hypergastrinemia → parietal-cell hypersecretion** (antral-predominant pattern) |
| **Duodenal ulcer pathway** | Excess acid → **gastric metaplasia in duodenal bulb** → H. pylori colonizes these islands → focal inflammation + ↓duodenal bicarbonate → ulcer |
| **Barrier breakdown** | Net result: ↓ mucus/bicarbonate, ↓ blood flow, ↑ acid → mucosal break deepens to submucosa = **peptic ulcer** |

```
Urease + flagella + BabA  → antral colonization
VacA + CagA               → epithelial damage
D-cell destruction        → ↑ gastrin → ↑ ACID
↓ mucus/↓ bicarbonate/↓ flow → DEFENCE FAILURE
                          ⇒ PEPTIC ULCER
```

📌 Eradication (triple therapy: PPI + clarithromycin + amoxicillin) cures ulcers and prevents recurrence.

> 🎯 "**Urease to survive, flagella to reach, BabA to stick, VacA/CagA to injure, ↑acid to finish** — H. pylori is necessary AND sufficient for most DUs."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q10. Write down the morphology and histological features of peptic ulcer disease.

### Gross morphology
- Usually **solitary**; round-to-oval, sharply demarcated ("punched-out"), **≤2 cm (DU often smaller than GU)**.
- Straight walls perpendicular; base clean and smooth; depth varies — reaches **submucosa ± muscularis propria**, may perforate serosa.
- Surrounding mucosa **congested but not heaped-up/nodular** (contrast carcinoma); radiating mucosal folds converge toward ulcer.
- Site: duodenal bulb (anterior/posterior wall) or lesser-curvature antrum.
- Adjacent gastric rugae flatten; vessels in base may show thrombosis (source of bleeding).

### Histology (the classic FOUR layers of the floor)

```
Surface  ① Fibrino-purulent exudate — fibrin strands + necrotic debris + PMNs
         ② Nonspecific acute inflammatory layer — neutrophil-rich granulation debris
         ③ GRANULATION TISSUE — proliferating capillaries, fibroblasts, chronic infiltrate
Base     ④ FIBROUS (COLLAGENOUS) SCAR — replaces muscularis propria; thick-walled
            thrombosed arteries (arteritis obliterans) at the base
```

- Muscularis mucosae interrupted; both margins show **chronic active gastritis** (H. pylori demonstrable with Giemsa/Warthin-Starry stain).
- Healing → fibrous scar with re-epithelialization; scarred ulcers deform the bulb ("cloverleaf").

> 🎯 "**Punched-out, clean-based, four-layered floor: exudate → PMNs → granulation → scar** with thrombosed vessel underneath."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q11. Mention the complications of peptic ulcer disease.

| Complication | Frequency | Features |
|---|---|---|
| 🔴 **Haemorrhage** | **15–20% (most common)** | Erosion of artery in floor (gastroduodenal/left gastric branch) → hematemesis/melena; may be massive |
| 🔴 **Perforation** | 5–10% | Anterior duodenal ulcer → sudden severe epigastric pain, board-like rigidity, shock; **air under diaphragm (free gas)** → chemical then bacterial peritonitis |
| **Penetration** | — | Posterior duodenal ulcer erodes into pancreas → boring back pain, elevated amylase (confused with pancreatitis) |
| 🔴 **Pyloric / gastric outlet obstruction** | ~5% | Edema/spasm early, fibrotic stricture later → projectile vomiting, succussion splash, hypochloremic hypokalemic metabolic alkalosis |
| **Malignant transformation** | Gastric only | Debatable — up to 10% of "gastric ulcers" prove malignant (biopsy all GUs); duodenal ulcers never malignant |
| **Intractability/recurrence** | — | Pain pattern becomes constant; refractory ulcer → search for ZES |

> 🎯 "**Bleeding 15–20% > Perforation 5–10% > Outlet obstruction 5%** · penetration posteriorly into pancreas."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q12. How will you differentiate a peptic (benign) ulcer from a malignant ulcer?

| Feature | **Benign peptic ulcer** | **Malignant ulcer (ulcerated carcinoma)** |
|---|---|---|
| Age | Younger (<50 yr typical) | Older (>50 yr) |
| Sex/history | DU/GU history, NSAID/H. pylori | Alarm features: weight loss, anaemia, anorexia |
| 🔴 Site | Antrum/lesser curvature, duodenal bulb | Greater curvature or fundus more suspicious |
| Size | Small (<2 cm) | Large (>2–4 cm) |
| Number | Solitary (DU rarely multiple) | May be multiple |
| 🔴 Margins | Sharp, punched-out, NOT raised; surrounding mucosa flat | 🔴 **Heaped-up, rolled, nodular, irregular margins** |
| Base | Clean, smooth, necrotic exudate | Necrotic, haemorrhagic, dirty, fungating mass |
| Rugae | Radiating folds converge to ulcer | Rugae abruptly cut off/thickened around mass |
| Depth | Deep, flask-shaped, may penetrate | Shallow crater within an obvious mass |
| Mobility | Mobile, no mass palpable | Fixed mass ± palpable lump |
| Symptoms | Meal-related pain relieved by antacids; episodic for years | Persistent pain unrelieved by food/antacids; rapid progression |
| Response to therapy | Heals with PPI/H. pylori eradication (repeat endoscopy confirms healing) | **Does NOT heal**; enlarges on repeat endoscopy |
| Biopsy/cytology | Chronic nonspecific inflammation, no atypia | 🔴 Dysplastic/invasive glands or signet-ring cells; positive brush cytology |
| Acid secretion | Normal/high | Often achlorhydric/hypochlorhydric |
| Prognosis | Cured medically/surgically | Depends on stage; 5-yr survival <25% advanced |

📌 **Rule: every gastric ulcer must be biopsied** — duodenal ulcers are virtually never malignant.

> 🎯 "**Heaped margins + big size + no healing + biopsy-positive = malignant; punched-out + clean base + heals = benign.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q13. Classify gastric carcinoma.

### 1. Lauren classification (most used)

| Feature | **Intestinal type** | **Diffuse type** |
|---|---|---|
| Frequency | More common; older men; declining incidence | Younger, slight female predominance |
| Precursor | 🔴 Chronic gastritis → atrophy → **intestinal metaplasia → dysplasia → carcinoma** (adenoma-carcinoma sequence) | No precursor; arises de novo |
| Associations | H. pylori, diet (nitrites/smoked food), environment | 🔴 **CDH1 (E-cadherin) loss**; hereditary diffuse gastric cancer |
| Histology | Well-formed tubular/papillary glands, mucin-secreting | 🔴 Poorly cohesive **signet-ring cells**, no glands, desmoplastic stroma |
| Gross | Polypoid/ulcerated | **Diffusely infiltrative — linitis plastica ("leather bottle")** |
| Prognosis | Better | Worse (late presentation, peritoneal spread) |

### 2. WHO classification
Tubular · Papillary · Mucinous (>50% extracellular mucin) · Signet-ring cell / poorly cohesive · Mixed.

### 3. Gross (Borrmann) classification
I Polypoid/exophytic · II Fungating · III Ulcerated (heaped margins) · IV Diffusely infiltrative (linitis plastica).

### 4. Early vs advanced
- 🔴 **Early gastric cancer = invasion limited to MUCOSA/SUBMUCOSA regardless of nodes** (T1) — curable, **>90% 5-yr survival**; detected by screening (Japan).
- Advanced = invasion beyond submucosa (muscularis propria or deeper).

> 🎯 "**Lauren: Intestinal (H. pylori-metaplasia, glands, better) vs Diffuse (CDH1, signet-ring, linitis plastica, worse)**; early = mucosa/submucosa only."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q15. Discuss the morphology of gastric carcinoma.

### Gross morphology (advanced)
| Pattern | Description |
|---|---|
| **Exophytic/polypoid (Borrmann I–II)** | Lobulated, friable mass projecting into lumen |
| **Flat/depressed** | Plaque-like mucosal thickening |
| **Excavated/ulcerated (III)** | Crater with 🔴 **heaped-up rolled margins** within a firm mass (vs punched-out peptic ulcer) |
| **Diffusely infiltrative (IV)** | 🔴 **Linitis plastica — "leather-bottle stomach":** rigid, thickened wall from submucosal signet-ring infiltration + desmoplasia; rugae flattened, no discrete mass |

### Microscopic morphology
- **Intestinal type:** well/moderately differentiated **tubular and papillary glands**, goblet/brush-border cells, extracellular mucin pools; adjacent **intestinal metaplasia + atrophy** in background mucosa.
- **Diffuse type:** sheets/single files of 🔴 **signet-ring cells** (large intracytoplasmic mucin droplet pushing crescentic nucleus to periphery — PAS/Alcian-blue positive), poorly cohesive, brisk **desmoplastic stroma**; permeates wall layer by layer.
- Grading: well/moderate/poorly differentiated (intestinal type); diffuse type by definition poorly differentiated.
- **Early gastric cancer:** any pattern confined to mucosa/submucosa — often superficial elevated/depressed small lesions found on screening.

### Spread (see Q17) and prognosis
Overall 5-yr survival <25%; early lesions >90%; nodal involvement markedly worsens outcome.

> 🎯 "**Four gross patterns; remember linitis plastica + signet-ring cells = diffuse type; heaped margins separate it from benign ulcer.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q16. Differentiate between gastric ulcer and duodenal ulcer.

| Feature | **Gastric ulcer (GU)** | **Duodenal ulcer (DU)** |
|---|---|---|
| Site | **Antrum, lesser curvature** | **First part (bulb)** |
| Cause | H. pylori 50–60%, NSAIDs prominent | 🔴 H. pylori **80–95%**, NSAIDs |
| Acid secretion | Normal or LOW (defect in defence) | 🔴 **HIGH** (hypersecretion) |
| Age | Older (50–60 yr) | Younger (30–50 yr) |
| Pain–food relation | Pain **worsened/worsens soon AFTER meals** (food stimulates acid on raw ulcer); weight LOSS common (fear of eating) | Pain **relieved by food**, recurs **2–3 h after meal/NIGHT pain**; weight maintained/gained |
| Vomiting | More common (outlet irritation) | Less common |
| Haematemesis vs melena | Hematemesis relatively more | Melena/bleeding from gastroduodenal artery |
| 🔴 Malignant potential | **Up to 10% malignant — BIOPSY all** | 🔴 **NEVER malignant** |
| Complications | Bleeding 15–20%, perforation 5–10%, outlet obstruction 5%, cancer | Bleeding (posterior → gastroduodenal artery), perforation (anterior), pyloric obstruction |
| Associated blood group | A | O |
| Gastritis background | Diffuse chronic gastritis present | Antral gastritis with duodenitis/metaplasia |
| Treatment response | Must exclude malignancy; heal slower | Rapid response to eradication/PPI |

> 🎯 "**GU = old, low acid, worse after food, loses weight, CAN be cancer** · **DU = young, high acid, hunger/night pain relieved by food, NEVER cancer.**"

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191

## Q17. Mention the sites of gastric carcinoma. How does gastric carcinoma spread?

### Sites
| Location | Frequency |
|---|---|
| 🔴 **Antrum/pyloric region** | **Most common (~50%)** |
| **Lesser curvature** | Second most common |
| **Body/anterior-posterior walls** | Next |
| 🔴 **Cardia/GEJ** | Rising incidence (obesity, GERD) |
| Greater curvature/fundus | Least common (a malignant ulcer here is suspect) |

### Pathways of spread
```
1. DIRECT (local)     → oesophagus (cardia tumours), duodenum,
                        transverse colon, pancreas, abdominal wall
2. LYMPHATIC          → perigastric → coeliac/portal nodes
                        → LEFT SUPRACLAVICULAR node = VIRCHOW NODE (Troisier sign)
                        → left axillary = IRISH NODE
3. HAEMATOGENOUS      → LIVER (via portal vein — most common distant site),
                        lungs, bone, brain
4. TRANSCOELOMIC      → ovary (bilateral signet-ring mets) = KRUKENBERG TUMOUR
                        → umbilicus = SISTER MARY JOSEPH NODULE
                        → peritoneum (carcinomatosis), pouch of Douglas (Blumer shelf),
                        pseudomyxoma-like mucinous seeding
```

📌 Staging uses TNM; **Virchow node + Krukenberg + Sister Mary Joseph are classic viva eponyms** — all from gastric carcinoma.

> 🎯 "**Antrum #1, cardia rising** · spread: Virchow (supraclavicular), Krukenberg (ovary), Sister Mary Joseph (umbilicus), liver via portal vein."

> 📖 Robbins 10e, Ch 17 (Gastrointestinal Tract), pp. 753–822 · 📗 Arif 15e (2025), Vol-2, Unit-I Gastrointestinal System, pp. 144–191
