<summary><b>Q1. List the causes of acute hepatitis. Give the positive findings in liver function tests in acute hepatitis.</b></summary>

### Causes of acute hepatitis

| Category | Causes |
|---|---|
| 🔴 **Viral (most important)** | **Hepatitis A** (fecal-oral) · **Hepatitis B** (parenteral/sexual/perinatal) · **Hepatitis C** · **Hepatitis D** (needs HBV) · **Hepatitis E** (fecal-oral; ~20% mortality in pregnancy) · Other viruses: **EBV, CMV**, HSV, varicella-zoster, yellow fever, dengue |
| **Drugs/toxins** | 🔴 **Acetaminophen (paracetamol — commonest cause of acute liver failure in Western series)**, isoniazid, halothane, methyldopa, phenytoin, anti-tubercular drugs; mushroom (*Amanita phalloides*) |
| **Alcohol** | Acute alcoholic hepatitis |
| **Autoimmune** | Type 1 / type 2 autoimmune hepatitis (acute presentation) |
| **Metabolic/vascular** | Wilson disease (acute decompensation), ischemic hepatitis ("shock liver" in hypotension/heart failure), Budd-Chiari syndrome, acute fatty liver of pregnancy/HELLP, Reye syndrome |

### Positive LFT findings in acute hepatitis

| Test | Finding | Typical value (Arif reference ranges) |
|---|---|---|
| 🔴 **ALT (SGPT)** | 🔴 **Markedly raised — hallmark of acute hepatocellular injury** (often >10× ULN; may exceed 1000 U/L); ALT > AST | Normal ≤40 U/L |
| **AST (SGOT)** | Markedly raised but usually lower than ALT | Normal ≤40 U/L |
| **Serum bilirubin** | Raised (mixed conjugated + unconjugated); jaundice appears when total bilirubin >2–2.5 mg/dL | Total normal 0.3–1.2 mg/dL; direct 0–0.25 mg/dL |
| **ALP & GGT** | Mildly raised (cholestasis if severe disease) | ALP 30–120 U/L; GGT M 11–50, F 7–33 U/L |
| **PT/INR** | 🔴 Prolonged in severe/necrotizing hepatitis — best index of severity (poorly synthesized clotting factors) | PT 12–14 s; INR ≈ 1 |
| **Albumin** | Usually normal early (long half-life ~20 days) | 3.5–5.0 g/dL |
| **Urine** | Bilirubin + urobilinogen positive (dark urine) | — |

> 🎯 "**Acute hepatitis = ALT >> AST (>10×) + raised mixed bilirubin + prolonged PT; viruses A/B/C/D/E top the list, paracetamol tops the toxins.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q2. Mention the viral markers of hepatitis with their diagnostic significance.</b></summary>

### Hepatitis A–E markers

| Virus | Marker | Diagnostic significance |
|---|---|---|
| **HAV** | 🔴 **IgM anti-HAV** | Recent/current acute infection (appears at onset, persists 3–6 months) |
| | IgG anti-HAV | Past infection/vaccination — immunity |
| **HBV** | 🔴 **HBsAg** | First marker to appear (before symptoms); persists >6 months = chronic carrier state |
| | 🔴 **Anti-HBs** | Appears after HBsAg disappears = recovery + protective immunity; sole marker after vaccination |
| | 🔴 **IgM anti-HBc** | Acute/recent infection; the ONLY marker during the **window period** (HBsAg gone, anti-HBs not yet risen) |
| | IgG anti-HBc | Past exposure/persistent infection (never indicates immunity alone) |
| | 🔴 **HBeAg** | Active viral replication + high infectivity; persistence predicts chronicity |
| | Anti-HBe | Replication has waned / infection peaked (lower infectivity) |
| | 🔴 **HBV DNA (PCR)** | Most sensitive marker of active replication/infectivity |
| **HCV** | 🔴 **Anti-HCV (ELISA)** | Exposure to HCV (past or present); cannot distinguish active vs resolved |
| | 🔴 **HCV RNA (PCR)** | Confirms ACTIVE infection; appears within days; used for genotype |
| **HDV** | IgM/IgG anti-HDV, HDV RNA, HDAg | HDV superinfection/co-infection (defective virus needs HBsAg coat); IgM anti-HDV = best marker of recent exposure |
| **HEV** | 🔴 **IgM anti-HEV** | Recent acute infection (esp. important in pregnant women — up to 20% mortality); HEV RNA PCR confirms |

📌 Key patterns: **HBsAg+ / anti-HBs− / IgM anti-HBc+ = acute HBV** · **HBsAg+ >6 months / anti-HBs absent = chronic carrier** · **anti-HBs+ / anti-HBc IgG± = immunity (infection or vaccine)** · **HBsAg−, anti-HBs−, IgM anti-HBc+ = window period**.

> 🎯 "**s = Surface present (infected); s-antibody = Safe (immune); c-IgM = Current; e = Escalating replication; window period = IgM anti-HBc only.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q3. Name the viruses commonly causing acute liver failure. Give the clinical features of liver failure.</b></summary>

### Viruses causing acute liver failure (fulminant viral hepatitis)

1. 🔴 **Hepatitis A virus** (commonest cause worldwide)
2. 🔴 **Hepatitis E virus** (esp. devastating in pregnancy)
3. 🔴 **Hepatitis B virus** (commonest in Asia/Mediterranean region; ± HDV co-/super-infection worsens it)
4. Rarely **HCV**, HSV, EBV, CMV, yellow fever
5. 📌 Viral hepatitis accounts for ~10% of all acute liver failure; overall commonest cause globally is **drug-induced (acetaminophen)** — worth mentioning as a non-viral contrast.

Pathology: **massive/submassive hepatic necrosis** with collapse of reticulin framework.

### Clinical features of liver failure

| Group | Features |
|---|---|
| 🔴 **Hepatic encephalopathy** | Disturbed consciousness: drowsiness → confusion → coma; **flapping tremor (asterixis)**, hyperreflexia, rigidity, seizures; **fetor hepaticus** (musty breath) |
| 🔴 **Coagulopathy/bleeding tendency** | Purpura, ecchymoses, bleeding from gums, puncture sites, GIT (↓ clotting factors II, V, VII, IX, X → ↑PT/INR) |
| **Jaundice** | Deep icterus (mixed hyperbilirubinemia) |
| **Cerebral edema** | Major cause of death in acute liver failure; raised intracranial pressure |
| **Metabolic derangement** | 🔴 Hypoglycemia (impaired gluconeogenesis/glycogenolysis), hyponatremia, hypokalemia, metabolic acidosis/respiratory alkalosis |
| **Renal failure** | 🔴 Hepatorenal syndrome (functional renal failure) |
| **Infection/sepsis** | Impaired immunity — bacterial/fungal sepsis common |
| **Cardiorespiratory** | Hypotension, hypoxemia, pulmonary edema |
| 📌 General | Nausea, vomiting, anorexia, marked weakness |

> 🎯 "**ALF viruses = A, E, B (±D): 'A-E-B kills fast'** · **Failure picture = Encephalopathy (asterixis + fetor) + Bleeding (↑PT) + Jaundice + Hypoglycemia + Renal failure.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q4. Name the viruses commonly causing chronic hepatitis. How chronic hepatitis can be confirmed in laboratory?</b></summary>

### Viruses causing chronic hepatitis

1. 🔴 **Hepatitis B virus** — chronicity in 5–10% of adults, but ~90% of perinatally infected infants
2. 🔴 **Hepatitis C virus** — chronicity in **80–90%** (major cause of chronic hepatitis in the West; significant in Bangladesh too)
3. 🔴 **Hepatitis D virus** — chronic in >80–90% after **superinfection** of a chronic HBV carrier (~10% with co-infection)
4. 📌 **HEV** — chronic only in immunocompromised (transplant/AIDS). **HAV never becomes chronic.**

📌 Chronic hepatitis definition: clinical/biochemical/serologic evidence of continuing hepatic inflammation and necrosis for **more than 6 months**.

### Laboratory confirmation of chronic hepatitis

| Step | Findings |
|---|---|
| 🔴 **Persistent abnormal LFTs >6 months** | Fluctuating/mildly raised ALT, AST (ALT > AST except alcoholism); raised bilirubin in activity |
| 🔴 **Serology** | **HBsAg positive for >6 months ± HBeAg/HBV DNA PCR** (active HBV) · **Anti-HCV positive + HCV RNA detectable by RT-PCR** (active HCV) · IgM anti-HDV/HDV RNA (HDV) |
| 🔴 **Liver biopsy — gold standard for severity** | Portal lymphoplasmacytic infiltrate crossing the limiting plate = 🔴 **interface (piecemeal) necrosis**; lobular spotty necrosis; fibrosis portal→bridging; clues to etiology: **ground-glass hepatocytes (HBV)**, **lymphoid follicles + steatosis (HCV)** |
| **Histologic scoring** | Biopsy gives **GRADE** (necroinflammatory activity) + **STAGE** (fibrosis: METAVIR/Knodell-Ishak) — guides treatment |
| **Quantitative DNA/RNA** | HBV DNA / HCV RNA viral load assesses replication & response to therapy |

> 🎯 "**Chronic = >6 months; viruses = B, C, D ('Bad Chronicity Duo = B+C'); confirm = persistent enzymes + seromarkers + biopsy showing interface hepatitis (grade + stage).**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q5. List the causes of chronic hepatitis. Mention the fates/outcomes of chronic hepatitis.</b></summary>

### Causes of chronic hepatitis

| Category | Causes |
|---|---|
| 🔴 **Viral** | **HBV (±HDV)**, **HCV** (majority); rarely HEV (immunosuppressed) |
| 🔴 **Autoimmune** | Type 1 (ANA/anti-SMA, adults) · Type 2 (anti-LKM-1, children); plasma-cell rich interface hepatitis, high IgG |
| **Drug-induced** | Isoniazid, methyldopa, nitrofurantoin, minocycline |
| **Alcohol/NASH** | Alcoholic steatohepatitis; non-alcoholic steatohepatitis (metabolic syndrome) |
| **Hereditary/metabolic** | Wilson disease, α1-antitrypsin deficiency, hemochromatosis |
| **Biliary/other** | PBC/PSC (chronic cholestatic hepatitis-like), cryptogenic |

### Fates/outcomes of chronic hepatitis

```
Chronic hepatitis (persistent interface hepatitis)
        │
        ├──► Resolution (rare, esp. after immune clearance/treatment — DAAs cure HCV in >95%)
        │
        ├──► Persistent "smoldering" disease (stable low-grade activity, carrier state in HBV)
        │
        ├──► Progressive fibrosis ── bridging fibrosis ──► CIRRHOSIS
        │                                                    │
        │                                                    ├─► Portal hypertension (varices, ascites, splenomegaly)
        │                                                    ├─► Hepatic failure (encephalopathy, coagulopathy, jaundice)
        │                                                    └─► HEPATOCELLULAR CARCINOMA (esp. HBV/HCV cirrhosis)
        │
        └──► Acute flare / acute-on-chronic liver failure (superinfection, drugs, alcohol)
```

📌 Risk of progression depends on grade/stage, viral load, alcohol use, co-infection (HIV), age at infection.

> 🎯 "**Causes: VIRUS + AUTOIMMUNE + DRUG + METABOLIC; fates: resolve – smolder – cirrhose – cancerize ('R-S-C-C').**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q6. List the liver function tests. What are changes in liver function test occurring in obstructive jaundice?</b></summary>

### List of liver function tests (Arif classification)

| Category | Tests | Normal values (typical Bangladeshi lab reference, Arif) |
|---|---|---|
| 🔴 **Pigment metabolism (excretory)** | Serum total/direct/indirect bilirubin; urine bilirubin & urobilinogen; stool stercobilin | Total bilirubin 0.3–1.2 mg/dL; direct 0–0.25 mg/dL; indirect 0.3–0.9 mg/dL |
| 🔴 **Enzymes — hepatocellular leakage** | ALT (SGPT), AST (SGOT), LDH | ALT/AST ≤40 U/L |
| 🔴 **Enzymes — cholestatic (canalicular/apical membrane)** | 🔴 **ALP, GGT**, 5′-nucleotidase | ALP 30–120 U/L; GGT M 11–50, F 7–33 U/L |
| 🔴 **Synthetic function** | Prothrombin time/INR (vitamin K response), serum albumin, A/G ratio, fibrinogen, protein electrophoresis | Albumin 3.5–5.0 g/dL; total protein 6–8 g/dL; A/G ratio 1.5–2.5; PT 12–14 s |
| **Detoxification/metabolic** | Serum ammonia, bromsulfophthalein (BSP) excretion, galactose tolerance, drug clearance (caffeine/lidocaine) | Ammonia <50 µmol/L |
| **Serum immunoglobulins** | IgG (chronic hepatitis/autoimmune), IgM (PBC/acute viral), IgA4 pattern (alcohol) | — |

### LFT changes in obstructive (posthepatic/cholestatic) jaundice

| Test | Change | Why |
|---|---|---|
| 🔴 **Serum bilirubin** | 🔴 **Conjugated (direct) bilirubin markedly raised** — may reach 20–30 mg/dL | Regurgitation of water-soluble conjugated pigment back into blood |
| 🔴 **Urine bilirubin** | Present (dark beer-colored urine) | Conjugated bilirubin is water-soluble → excreted |
| 🔴 **Urinary urobilinogen** | Absent/reduced | No bile reaches gut → no urobilinogen formation |
| 🔴 **Stool** | Pale/clay-colored (acholic) | Absence of stercobilin |
| 🔴 **ALP + GGT** | 🔴 **Markedly raised (>3–4× ULN; ALP rises more than transaminases)** | Canalicular enzyme induction/regurgitation from damaged biliary epithelium |
| **ALT/AST** | Mild-moderate rise (<5× ULN) | Secondary hepatocyte stress |
| 🔴 **Prothrombin time** | Prolonged BUT 🔴 **corrected by parenteral vitamin K** | Fat-soluble vit K malabsorption (no bile salts) |
| **Serum cholesterol/lipids** | Raised (xanthelasma/xanthoma in chronic obstruction) | Regurgitation + impaired excretion |
| **Serum albumin** | Normal (early); falls late in secondary biliary cirrhosis | Synthetic function initially preserved |
| 📌 Others | Serum bile salts ↑ (pruritus); bradycardia | Bile salt retention |

> 🎯 "**Obstruction = Direct bilirubin ↑↑ + dark urine + clay stool + NO urobilinogen + ALP/GGT ↑↑ + vitamin K-correctable PT — 'the DUCT picture'.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q7. Give the pathological definition and classification of jaundice.</b></summary>

### Pathological definition

🔴 **Jaundice (icterus) = yellowish discoloration of skin, sclerae and mucous membranes due to accumulation of bilirubin in blood and tissues when serum bilirubin exceeds ~2–2.5 mg/dL** (normal total 0.3–1.2 mg/dL). Scleral staining = icterus; bilirubin binds elastic tissue, hence sclera stained first.

### Classification

| Type | Mechanism | Examples |
|---|---|---|
| 🔴 **1. Prehepatic (hemolytic)** | Excess bilirubin PRODUCTION (unconjugated) overwhelming normal liver capacity | Hemolytic anemias (hereditary spherocytosis, sickle cell, thalassemia, G6PD deficiency, autoimmune hemolysis, malaria, incompatible transfusion), ineffective erythropoiesis (megaloblastic/sideroblastic anemia), resorption of large hematoma |
| 🔴 **2. Hepatic (hepatocellular)** | Defective UPTAKE, CONJUGATION or SECRETION by diseased hepatocytes (mixed unconjugated + conjugated) | Viral/drug/alcoholic hepatitis, cirrhosis; inherited: Gilbert syndrome, Crigler-Najjar type I/II (conjugation defects), Dubin-Johnson (MRP2 defect)/Rotor syndromes (secretion defects); neonatal physiological jaundice (immature UGT1A1) |
| 🔴 **3. Posthepatic (obstructive/cholestatic)** | EXTRAHEPATIC or INTRAHEPATIC BILE DUCT obstruction → regurgitation of conjugated bilirubin | Choledocholithiasis (commonest), carcinoma of head of pancreas/ampulla/cholangiocarcinoma, strictures, biliary atresia, ascending cholangitis, PBC/PSC |

📌 Physiologic sub-classification: **unconjugated hyperbilirubinemia** (prehepatic + uptake/conjugation defects) vs **conjugated hyperbilirubinemia** (hepatocellular + obstructive).

> 🎯 "**Jaundice = bilirubin >2–2.5 mg/dL; types = PRE-hepatic (make too much) · HEPATIC (can't handle it) · POST-hepatic (pipe blocked) — 'Make–Handle–Block'.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q8. Mention the causes of neonatal jaundice with the pathogenesis.</b></summary>

### Causes of neonatal jaundice

| Type | Causes |
|---|---|
| 🔴 **Physiological jaundice** (unconjugated; appears day 2–3, peaks day 4–5, clears by 2 weeks; <12–15 mg/dL) | Immaturity of the newborn liver + increased RBC load |
| 🔴 **Breast-milk jaundice** | β-glucuronidase in milk; prolonged unconjugated jaundice, benign |
| 🔴 **Hemolytic (pathologic, unconjugated)** | **Rh/ABO incompatibility (hemolytic disease of newborn)**, hereditary spherocytosis, G6PD deficiency — risk of 🔴 **kernicterus** (bilirubin encephalopathy) |
| **Congenital conjugation defects (unconjugated)** | **Crigler-Najjar type I** (absent UGT1A1 — fatal without transplant), **type II** (partial), Gilbert syndrome |
| **Neonatal hepatitis (conjugated)** | TORCH infections (CMV, toxoplasma, syphilis), sepsis; giant-cell transformation |
| 🔴 **Obstructive (conjugated)** | 🔴 **Extrahepatic biliary atresia** (⅓ of neonatal cholestasis — acholic stools, dark urine; needs Kasai portoenterostomy), choledochal cyst, bile plug syndrome |
| **Metabolic/endocrine** | Galactosemia, α1-antitrypsin deficiency, tyrosinemia, hypothyroidism, cystic fibrosis |
| **Iatrogenic** | Total parenteral nutrition, umbilical catheter complications |

### Pathogenesis of physiological jaundice of the newborn

```
Newborn liver
   ├── Immature UDP-glucuronyl transferase (UGT1A1) activity (~1% of adult level)
   │        → defective CONJUGATION of bilirubin
   ├── Increased RBC mass + shorter RBC lifespan (~90 days)
   │        → increased bilirubin LOAD
   ├── Absent gut flora + sluggish intestinal motility
   │        → poor conversion of bilirubin to urobilinogen/excretion
   └── High intestinal β-glucuronidase
            → deconjugates bilirubin → enterohepatic REABSORPTION ↑
                            ↓
        Unconjugated (indirect) hyperbilirubinemia
                            ↓
     Yellow staining day 2–5, resolves as UGT matures (~2 weeks)
                            ↓
     If severe/unconjugated >20–25 mg/dL → free bilirubin crosses BBB
                            ↓
        KERNICTERUS (basal ganglia/brainstem staining)
```

> 🎯 "**Neonate's 4 hits = immature UGT + extra RBC load + no gut flora + reabsorption ('UGT-RBC-flora-reabsorb'); danger word = KERNICTERUS.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q9. How the types of jaundice can be differentiated without blood test?</b></summary>

### Clinical differentiation (history, examination, urine/stool inspection)

| Feature | 🔴 Prehepatic (hemolytic) | 🔴 Hepatocellular | 🔴 Obstructive |
|---|---|---|---|
| Depth of jaundice | Mild lemon-yellow tint | Moderate | Deep greenish-yellow (biliverdin) |
| **Urine color** | 🔴 **Normal color ("acholuric jaundice")** — no bilirubin (unconjugated = insoluble, albumin-bound) | 🔴 Dark/yellow-brown (bilirubin+) | 🔴 Very dark, "beer/tea-colored" (bilirubin++) |
| **Stool color** | Dark (increased stercobilin) | Normal/slightly pale | 🔴 **Pale, clay/putty-colored (acholic)** |
| Pruritus (scratch marks) | Absent | Mild | 🔴 Marked (bile salt deposition) |
| Anemia/pallor | 🔴 Prominent (hemolysis); jaundice without dark urine | Variable | Absent |
| Splenomegaly | 🔴 Common (hemolytic) | May be present (portal HTN) | Absent |
| Prodrome (fever, myalgia, anorexia, RUQ ache) | Absent | 🔴 Suggestive of viral hepatitis | Absent |
| Colicky RUQ pain radiating to shoulder/back | Absent | Absent | 🔴 Suggests stone; painless progressive jaundice + palpable nontender GB = carcinoma head of pancreas (**Courvoisier sign**) |
| Stigmata of chronic liver disease (spider naevi, palmar erythema, gynecomastia, ascites, caput medusae) | Absent | 🔴 Present in cirrhosis | Absent early |
| Bradycardia + xanthelasma | Absent | Absent | Suggestive of chronic cholestasis |
| Family history | Hemolytic disorders | Autoimmune/hepatitis contact | Gallstones/cancer |

> 🎯 "**No-lab triad: look at URINE (clear=hemolytic, dark=hepatic, very dark=obstructive), STOOL (dark=hemolytic, clay=obstructive), and SCRATCHES (itch=obstruction) + spleen says hemolytic, spiders say hepatic, colic says stone.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q10. Mention the causes of prehepatic jaundice. How prehepatic jaundice can be diagnosed by liver function test?</b></summary>

### Causes of prehepatic (hemolytic) jaundice

| Mechanism | Causes |
|---|---|
| 🔴 **Extravascular hemolysis (increased destruction)** | **Hereditary**: hereditary spherocytosis, elliptocytosis, G6PD deficiency, pyruvate kinase deficiency, sickle cell/thalassemia/hemoglobinopathies · **Acquired**: autoimmune hemolytic anemia, malaria, sepsis, snake venom, incompatible blood transfusion, mechanical valves, DIC/microangiopathic hemolysis |
| 🔴 **Ineffective erythropoiesis** | Megaloblastic anemia (B12/folate), sideroblastic anemia, thalassemia major — RBCs destroyed in marrow before release |
| **Other sources of heme** | Massive internal hemorrhage resorption, large hematoma breakdown |

### LFT diagnosis of prehepatic jaundice

| Test | Finding | Explanation |
|---|---|---|
| 🔴 **Serum bilirubin** | 🔴 **Unconjugated (indirect) bilirubin raised — usually <5 mg/dL**; direct fraction NORMAL | Overproduction exceeds hepatic conjugating capacity |
| 🔴 **Urine bilirubin** | 🔴 **ABSENT ("acholuric jaundice")** — indirect bilirubin is insoluble & tightly albumin-bound | Cannot be filtered by glomerulus |
| **Urine urobilinogen** | 🔴 Increased (+++) | More bilirubin reaches gut → more urobilinogen absorbed |
| **Stool** | Dark — increased stercobilin | As above |
| 🔴 **ALT, AST** | Normal | Hepatocytes intact |
| 🔴 **ALP/GGT** | Normal | No cholestasis |
| 🔴 **Albumin, PT** | Normal | Synthetic function preserved |
| 📌 Supporting (non-LFT) | Anemia + 🔴 reticulocytosis, ↑LDH, ↓serum haptoglobin, positive Coombs test (autoimmune), osmotic fragility (spherocytosis), peripheral smear fragments/sickled cells | Confirms hemolysis |

> 🎯 "**Prehepatic LFT = INDIRECT ↑ (<5), direct normal, urine CLEAR (acholuric), urobilinogen ↑, ALL ENZYMES NORMAL — plus anemia + retics. 'Indirect-up, Urine-clear, Enzymes-calm.'**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q11. What are the desired changes in liver function test in a case of hepatocellular jaundice?</b></summary>

### LFT changes in hepatocellular (hepatic) jaundice

| Test | Expected change | Explanation |
|---|---|---|
| 🔴 **ALT/AST** | 🔴 **Markedly raised (often >10× ULN); ALT > AST** — the defining feature (exception: alcoholic liver disease AST:ALT ≥2:1) | Leakage from necrotic hepatocytes |
| 🔴 **Serum bilirubin** | 🔴 **Mixed rise — BOTH conjugated and unconjugated elevated** (usually moderate, 5–10 mg/dL) | Impaired uptake + conjugation + secretion; regurgitation through damaged canaliculi |
| **ALP/GGT** | Mild-to-moderate rise (less than bilirubin would suggest in obstruction; ALP <2–3× ULN) | Some canalicular damage/secondary cholestasis |
| 🔴 **Urine bilirubin** | Present (dark urine) | Conjugated portion is water-soluble |
| **Urine urobilinogen** | Increased EARLY (defective re-excretion); decreased LATE if severe cholestasis supervenes | Dual mechanism |
| 🔴 **Serum albumin** | Low in chronic disease (synthetic failure); normal in pure acute hepatitis early | Reduced synthesis |
| 🔴 **Prothrombin time/INR** | Prolonged AND 🔴 **NOT fully corrected by parenteral vitamin K** | True deficit of clotting factor SYNTHESIS (vs obstruction where it corrects) |
| **Total protein/A:G ratio** | Reversal of A:G ratio in chronicity; 🔴 hypergammaglobulinemia (IgG in chronic hepatitis/autoimmune) | Polyclonal globulin stimulation |
| 📌 Supporting | Positive viral serology (HBsAg, anti-HCV etc.), autoantibodies (ANA/SMA/LKM), raised ferritin/copper studies as per cause | Etiologic workup |

### Quick contrast table (exam favorite)

| Parameter | Prehepatic | Hepatocellular | Obstructive |
|---|---|---|---|
| Bilirubin | Indirect ↑ (<5) | Mixed ↑ | Direct ↑↑ (may be >20) |
| ALT/AST | Normal | ↑↑↑ (ALT>AST) | Mild ↑ |
| ALP/GGT | Normal | Mild ↑ | ↑↑↑ (ALP dominant) |
| Urine bilirubin | Absent | Present | Present |
| Urobilinogen (urine) | ↑↑ | Early ↑ / late ↓ | Absent |
| Stool | Dark | Normal/pale | Clay-colored |
| PT prolongation | None | Present, NOT corrected by vit K | Present, CORRECTED by vit K |
| Albumin | Normal | ↓ (chronic) | Normal (early) |

> 🎯 "**Hepatocellular = ALT king (↑↑↑) + MIXED bilirubin + PT that vitamin K CANNOT fix + falling albumin — 'the failing FACTORY pattern'.**"

<summary><b>Q12. Give pathogenesis and outcome of hepatitis B viral infection.</b></summary>

### Pathogenesis of HBV infection

- 🔴 **Transmission:** parenteral (blood products, needles), sexual, perinatal (dominant route in endemic regions like Bangladesh).
- Virus (partially double-stranded DNA hepadnavirus) enters hepatocytes via **NTCP receptor** → uncoats → **cccDNA** persists in nucleus → transcription/replication via RNA intermediate using reverse transcriptase.
- 🔴 **Hepatocyte injury is IMMUNE-MEDIATED, not cytopathic:** CD8+ cytotoxic T lymphocytes recognize viral peptides (HBcAg/HBeAg) on infected hepatocytes → apoptosis/necrosis; humoral responses form immune complexes (vasculitis, glomerulonephritis, serum sickness-like prodrome).
- Weak/ineffective T-cell response → viral persistence → chronic carriage; vigorous response → clearance.
- **Ground-glass hepatocytes** = swollen ER stuffed with HBsAg.

```
HBV entry (NTCP receptor on hepatocyte)
      ↓
cccDNA in nucleus → viral proteins (HBsAg, HBcAg, HBeAg, HBx, polymerase)
      ↓
CD8+ CTL attack antigen-presenting hepatocytes  →  hepatocyte APOPTOSIS/NECROSIS
      ↓                                    ↓
(vigorous response)              (weak/ineffective response)
ACUTE hepatitis                  PERSISTENT low-grade infection
      ↓                                    ↓
Clearance: HBsAg↓ → anti-HBs↑    CHRONIC hepatitis (5–10% adults; ~90% infants)
                                           ↓
                              Chronic inflammation → cytokines (TNF-α, TGF-β)
                                           ↓
                     Stellate cell activation → fibrosis → CIRRHOSIS (20–30% of chronic)
                                           ↓
                    Integration of HBV DNA + HBx transactivator + regeneration cycles
                                           ↓
                       HEPATOCELLULAR CARCINOMA (cirrhosis → HCC 2–3%/yr)
```

### Outcomes of HBV infection (adults)

| Outcome | Frequency |
|---|---|
| Subclinical/asymptomatic infection → recovery | ~65% |
| Acute icteric hepatitis → recovery | ~25% |
| Fulminant hepatitis (massive necrosis) | <1% |
| 🔴 **Chronic hepatitis/carrier** | **5–10% of adults; ~90% if infected perinatally** |
| Chronic → cirrhosis over decades | 20–30% of chronics |
| Cirrhosis → HCC | 2–3% per year |
| Recovery with durable immunity | Anti-HBs develops, HBsAg cleared |

> 🎯 "**HBV story: enter via NTCP → cccDNA hides → CD8 kills the CELL not the virus; adults 5–10% chronic but babies ~90%; chronic → cirrhosis → HCC via HBx — 'B = Blood, Baby, Bad outcome'.**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405

<summary><b>Q13. Give the lab diagnosis of viral hepatitis.</b></summary>

### A. Non-specific laboratory tests

| Test | Finding |
|---|---|
| ALT/SGPT, AST/SGOT | 🔴 Markedly raised (hepatocellular pattern; often >1000 U/L in acute phase) |
| Bilirubin (total/direct) | Raised; urine bilirubin + urobilinogen positive |
| ALP/GGT | Mildly raised |
| PT/INR | Prolonged = severity indicator (prognostic in fulminant hepatitis) |
| CBC | Leukopenia with relative lymphocytosis (viral), atypical lymphocytes (EBV/CMV) |
| Serology for other causes excluded | ANA/ASMA (autoimmune), iron/copper studies |

### B. Specific serologic/molecular diagnosis

| Virus | Acute diagnosis | Past/immunity | Active replication | Notes |
|---|---|---|---|---|
| 🔴 **HAV** | 🔴 **IgM anti-HAV** (ELISA) | IgG anti-HAV | — (PCR research) | Fecal-oral; never chronic |
| 🔴 **HBV** | 🔴 **HBsAg + IgM anti-HBc** | Anti-HBs (+/- anti-HBc IgG) | 🔴 **HBeAg + HBV DNA PCR** | Window period = isolated IgM anti-HBc; HBsAg >6 months = chronic |
| 🔴 **HCV** | Anti-HCV ELISA (may be negative early — screen 3rd-gen ELISA then confirm) | Anti-HCV persists | 🔴 **HCV RNA RT-PCR (quantitative + genotype)** | Anti-HCV does NOT prove active disease; RNA does |
| **HDV** | IgM anti-HDV, HDAg | IgG anti-HDV | HDV RNA PCR | Always test with HBsAg-positive patients |
| 🔴 **HEV** | 🔴 **IgM anti-HEV** | IgG anti-HEV | HEV RNA PCR | Especially test in pregnant women with acute hepatitis |
| EBV/CMV | IgM VCA (EBV), IgM CMV | IgG | PCR | Heterophile/Monospot positive in EBV |

📌 Best practice sequence: acute hepatitis picture → order **IgM anti-HAV, HBsAg, IgM anti-HBc, anti-HCV (with HCV RNA), IgM anti-HEV**; add HBV DNA/HCV RNA for confirmation and monitoring.

> 🎯 "**Lab dx recipe: enzymes say WHERE, serology says WHO — IgM = now, IgG = gone; HBsAg = infected, anti-HBs = immune, RNA/DNA PCR = replicating. 'IgM-now, IgG-past, PCR-active.'**"

> 📖 Robbins 10e, Ch 18 (Liver and Gallbladder), pp. 823–880 · 📗 Arif 15e (2025), Vol-2, Unit-I Liver and Biliary Tract, pp. 192–224 · Unit-II Liver Function Test and Jaundice, pp. 392–405
