## 🧭 How this notes set works
- Read a section's big-picture classification first (ties the whole chapter together).
- Work through the ❓/✅ flashcards — each card is one short focused question; try to answer out loud before opening the answer.
- Test yourself with the 🎯 True/False quiz blocks under each topic, then reveal the green T / red F answers.
- Trust 🔴 blocks as your minimum pass list; add 📌 then 🎯 as time allows.
- Every chapter ends with a Rapid-Fire ❓/✅ one-liner sweep for last-minute viva/written revision.
<b>💡 Abbreviation policy (read once)</b>
Every abbreviation in these notes is expanded in full the <b>first time it appears</b> in each chapter (e.g., <b>AAA</b> = abdominal aortic aneurysm, <b>PAN</b> = polyarteritis nodosa, <b>ADPKD</b> = autosomal dominant polycystic kidney disease, <b>SLE</b> = systemic lupus erythematosus, <b>TNM</b> = tumour–node–metastasis staging). If you ever meet an acronym without its expansion, it is a prior-chapter expansion carried forward.
